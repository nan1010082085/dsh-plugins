# storyboard-director（虚拟导演）

## 职责
剧本 → 分镜指令。**改编，不是照抄**：取尽剧本信息+补完留白+扩写成可拍的画面。素材是演员与布景（character/scene/prop-studio 供给，只管一致性），风格是呈现效果（style-* 提供），本 skill 管「这场戏怎么拍」。

## 标准格式（正文＝参考级样例，2026-10-30 用户供，见 references/prompt-format.md §九）

三大项，仅此而已：
- **【基础设定】**：@资产 + 丰富完整的描述（形象/状态/机制/当镜动作），描述本身要有戏
- **【氛围与画质】**：风格核心 / 视觉基调 / 色彩与影调
- **【画面内容】**：**时间序列动作叙事**——动词链（掏出→按住→充能→抛出）、事件时序（片刻后…）、精确时间锚（爆炸后 0.5 秒）、声音自然织入。构图/景别/运镜各一行，简短。

禁图像思维：构图占比堆砌≠戏；视频是时间艺术，写「这几秒发生什么」，不是「画面长什么样」。

**真人实拍·多镜单视频变体（2026-11-05 用户供参考级样本）**：规格块共享（摄影机/胶片/光线）+ 素材语义引用行 + 双格式镜头块（详式=镜头N｜时间码｜秒数｜场景+入点与动作+本镜限制；简式=[景别｜机位｜主体]+白描+<音效>[硬切]），单条指令承载多镜连续时间码，见 `references/live-action-instruction-spec.md`。

## 工作流（2026-10-30 用户方案）
六步：剧本拆解→导演策略→镜头拆分表→逐镜指令填充→素材映射/后期清单→自检。

## 硬要求（用户原话来源，无杜撰）
- 改编后观感必须强于剧本原文；薄=打回（2026-10-30 用户令）
- 每集须有背景介绍（导演改写的观众版）+ 开场引入（2026-10-30 用户令）
- 怪物/角色首登场给全身亮相镜，局部特写不做首秀（2026-10-31 用户令）
- 双主体接触写轮廓分离（治穿模，2026-10-30 实证有效）
- 位移镜写死方向与谁动（治倒退，2026-10-30 实证有效）
- 提示词禁：参考图文字描述/括号标注/标签句/名条字幕入画/文学修辞（2026-10-30 用户令）
- 台词唯一出处；声音绑定动作与事件（2026-10-30 用户方案）
- 道具形态三要素无歧义（材质/颜色/结构）（2026-10-30 实证）
- 惊悚词降浓度（平台审核，2026-10-28 实证）
- 出片模型：即梦 seedance_2.0_fast_vip / xyq 2.0fast（用户点名）；参考图只在一致性刚需时挂（2026-10-31 样例对照实证：多参考杀构图）
- 观众买单是唯一判定；机器可读只是底线
