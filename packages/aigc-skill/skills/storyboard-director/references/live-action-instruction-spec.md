# 真人实拍出视频指令设计规范（live-action-instruction-spec）

> 来源：用户供参考级出视频指令样本（韩剧校园电影质感，2026-11-05）+ 同日用户令提炼。
> 适用：真人实拍质感剧集的**单视频多镜**出片指令。示例一律占位（角色A/少女/生物X），剧内数据住 assets.json/Notion。
> 与 §九四段式的关系：四段式是单镜/通用骨架；本文件是**规格块共享 + 多镜时间码**的长指令变体，画面内容段的「分镜N（时间码）」模式的完整工程化。无字数上限（2026-11-05 用户令，实证单条 917–1288 字正常出片）。

## 一、指令总体结构（自上而下，顺序固定）

```
严禁生成BGM和字幕                ← 首行负向兜底（唯一负向通道：字幕/音频）

【全局核心基础设定】              ← 规格块：一份多镜共享，只写不随镜变的量
摄影机 / 胶片色彩 / 帧率快门 / 画幅 / 画质

【光线】                         ← 规格块：色温量化 + 脸部效果清单 + 人工布光 + 禁项

【全局规格】                     ← 比例/形态限制句（如「生物X 巴掌大小」）

<素材引用行>                     ← 语义名[image] 分组列举

<镜头块 ×N>                      ← 时间码连续，镜与镜之间用 --- 分隔
```

## 二、全局核心基础设定（写法）

逐行写死，不用质量词堆砌，用**器材与流程名词**说话：

- **摄影机**：机型 + 成像格式 + 镜头组（如「ARRI ALEXA LF，ARRIRAW 4.5K Open Gate 成像审美。镜头组：ARRI Signature Prime」）。
- **胶片色彩**：胶片模拟 + 色彩流程 + 印片仿真三层写全（如「Kodak VISION3 250D 5207 胶片色彩模拟，LogC3 进 ACEScct，叠加轻度 Kodak 2383 Print Film Emulation」），再写颗粒/高光滚降/肤色规则。
- **帧率**：fps + 快门（24fps，快门 1/48）+ 禁变速句（「全程正常速度，禁止慢动作、升格、抽帧、加速台词和速度渐变」）。
- **画幅**：比例 + 分辨率 + 质感定性（16:9，4K，电影级真人实拍质感）。
- **画质**：质感档一句话（「顶级韩剧大制作情感戏质感」）+ **保留真实细节清单**（皮肤毛孔/眼下纹理/睫毛/碎发/唇纹/衣料纹理/织物质感）+ **禁项**（禁塑料皮肤、过度磨皮、廉价柔焦、动漫化五官、假面感、CG 感、陶瓷肌）。
- 实物文字规则：剧情实物（胸牌/表格/名单）允许保留，但不拍可读文字特写，信息走对白；禁悬浮文字与乱码大字。

## 三、【光线】块（写法）

1. **方向性主光**：来源 + 方向 + 色温量化（「主光约 4600K 暖金色午后阳光，阳光从人物左侧窗户照进来」）+ 受光部位清单（发丝/额角/睫毛/鼻梁/颧骨/唇峰）。
2. **「人物脸部必须显得」清单**：5–7 条可见效果（发丝通透、睫毛边缘柔和描光、鼻梁唇峰细腻高光、阴影柔和但立体、脸颊不过曝、面部轮廓干净）——把「好看」翻译成可验收的像素事实。
3. **人工布光**（三点 + 负补光，逐条写色温与作用）：
   - 头部侧后方隐藏式窄幅条形柔光灯（4800K）勾轮廓；
   - 正前方低位反光板 + 低强度柔光灯（4300K）补眼窝/虹膜/暗部；
   - 背窗侧负补光吸反射，防脸发黄发平。
4. **禁项**：禁任何灯光器材器械生成到画面当中。

## 四、比例/形态限制句（防漂移核心手段）

- 全局写一次（「生物X 巴掌大小」），**并在每镜「本镜限制」逐镜重复**——多镜长指令里限制句必须逐镜出现，只写全局必漂。
- 台词外标注语种与情绪/语速（（韩语，语速放缓）{…}），外语台词用花括号包裹。

## 五、素材引用行

- 语法：`语义名[image]`（画布内即 `语义名{{node:nodeId}}`），**语义名=职责标签**，不是裸编号：场景、场景反打（位置关系/影调参考）、影调参考、角色名、生物名分色变体（粉光生物X/绿色生物X/白生物X/幽灵生物X）、角色声线参考（音频锚：「角色A声线参考 {{node:…}}」）。
- 排列：按 场景 → 场景反打 → 角色 → 生物/宠物 分组；一镜用不到的不列。
- 用法双形态：成行列清单（列在镜头块之前）＋ 镜内内联（「生物X[image] 蹦在最前面」）。
- 引用≠免描述：每个入场主体仍要在镜内写形态/动作。

## 六、镜头块（双格式）

**详式**（多人/多物/有比例约束的镜）：

```
**镜头 N｜mm:ss.cs—mm:ss.cs｜X.XX 秒｜场景[image]**
<入画物/本镜主体>：语义名[image] 专属说明——形态/比例再锚。
入点与动作：<与上镜末帧衔接的入点状态>……<动词化动作链，关键句可加粗>。
本镜限制：<该镜独有的限制，全局限制句逐镜重复>。
```

**简式**（单主体短镜）：

```
镜头N (mm:ss–mm:ss)：[景别｜机位｜主体] 画面白描（动作+情绪+服装物理细节），<音效>。[硬切]
```

- 时间码**连续不重叠**（01:49.90—01:51.90、01:51.90—01:53.10…），单视频承载多镜，镜间用 `---` 分隔。
- 同事件连镜组写法：一个动作拆 N 个机位连镜（侧近→侧面→俯拍），每镜只推进一拍（实证：064a/b/c 三连镜 2.0s/1.2s/1.2s）。
- **入点与动作**字段治连贯：每镜入点=上镜动作末态，这是多镜单视频保连贯的核心机制。
- 台词行内联：`角色名（语种，语速/情绪）{台词}`；音效 `<声效描述>` 绑定具体动作；转场 `[硬切]`。
- 每镜一拍：一个动作一个运镜；>15s 自动分段。

## 七、分镜设计要点（从样本提炼）

1. **镜长实证分布**：1.2–3.0 秒/镜为主（情绪节拍镜 1.2s，动作镜 2–3s），比教科书短——微短剧节奏。
2. **连镜组**：同一动作多机位推进（俯拍过道/侧跟/反打），入点衔接上镜末态，镜头切换即机位切换，不用转场特效（[硬切] 为主）。
3. **限制逐镜重复**：比例句（巴掌大）/形态句（四肢细小贴布慢慢挪动）在每镜内以「本镜限制」重写一遍，措辞可微变但约束不变。
4. **主体明确行**：[景别｜机位｜主体] 三元组开头，主体写**谁**（四只生物X/角色A 正面），群像镜数清个数。
5. **音效绑定动作**：`<椅子倒地声、惊叫声>` 与画面事件同步，一镜一组，不写泛氛围。
6. **分辨率按镜别分档**（引擎计费优化）：特写/单人镜可 480p，多数镜 720p——分档是后端方言，按当期计费表定。

## 八、自检与已知坑

- **重复块去重**：长指令规格块拼装易出「【光线】重复两次」手误（样本实证）——交付前去重自检；`tools/prompt_selfcheck.py` 已加重复块检测。
- **一致性核对清单**（多视图素材进指令前）：胸牌文字/徽章位置/痣的位置/开衩处内搭，跨视图核对一致再挂载。
- 无字数上限；每镜 ≥250 字保底（五道硬闸 1）。违禁废话词/裸英文运镜词照过 `prompt_selfcheck.py`。
- 生成后验真、花钱门、Notion 状态闸照旧（`shared/hard-gates.md`），本文件只管指令怎么写。


## 时间轴对时（2026-11-05 成片 ffprobe 实测，硬规则）

成片实测（seedance_2.5，下载成片量时长）：**成片时长精确 = 生成参数 `durationSeconds`**（4s 档实测 4.064s、8s 档实测 8.064s，+0.064s 为容器封装尾），**指令里的时间码不是模型时间轴**——时间码覆盖超出 `durationSeconds` 的内容会被模型压缩或砍掉（实测：时间码覆盖 8.0s 的两镜指令成片只有 4.06s；覆盖 12.5s 的五镜指令成片 8.06s）。12 条实证生产 prompt 仅 3 条严格对时，其余靠模型自由裁剪=翻车面。

对时三条：

1. **总长对账**：一条指令的时间覆盖总长（末镜终点−首镜起点）必须 = 生成时长（±0.5s），出片前过 `prompt_selfcheck --duration N` ⑦ 机检。怎么拍随便，拍多久要对上账——对时是防翻车防烧积分，不是限制创作。
2. **时间轴全篇统一**：视频轴（00:00.00 起算，**推荐**）或剧本轴（绝对时间码，如 01:49.90）二选一，禁止混用；用剧本轴必须自行换算，保证覆盖总长仍 = 生成时长。
3. **快切镜**：单镜 <4s 按 4s 出、剪辑时裁短（计费按 max(4, 镜时长)），时间轴上仍按实际秒数排。
