# 镜头时长与生成策略（分类-合成体系）

> 核心规律：时长按**镜头功能**分配，不随机。
> **镜长统一口径（2026-10-31 批1 定案，用户已批；三处互指警告已解除）**：**单镜 3–5s 主流、快节奏 2–3s**（社区 ASL 口径带源：批4 §2.2——百度文库 90 分钟片约 600–800 镜、每 3–10 秒剪接、平均约 3–5 秒；CSDN「节奏强时平均镜头时长压到两三秒」；对话镜可上探、卡点镜下探至 1–2s。数值为经验区间，无官方/行业标准，ASL 方法论有学术谱系 UChicago Cinemetrics 作背书）＋ **后端官方时长上限分代**（**官方** API 1520757：Seedance 2.5=4–30s 或 -1、2.0=4–15s 或 -1、1.0=2–12s；生成侧下限 4s，不足 4s 按 4s 出后裁）。
> 〔注记：原本文件「1–4s」headline 口径已被 2026-10-31 镜长定案校正；selfcheck-7「4–8s」/ pacing-templates「1.5–4s」同步校正，三方互指警告全部解除。〕

## 一、时长 × 功能匹配表

| 时长 | 适合镜头类型 | 景别/运镜特征 | 叙事作用 | 生成难度【推测·未验证】 |
|------|------------|--------------|---------|---------|
| **1–3 秒** | 动作切分、冲击特写、转场过渡 | 特写/大特写、快推快拉、手持感 | 紧张感、细节强调、配音效 | ⭐ 极低 |
| **3–5 秒** | 简单叙事、单步动作、反应镜头 | 近景/中近景、固定/缓运镜 | 推进剧情、人物反应 | ⭐⭐ 低 |
| **5–8 秒** | 对话、情绪渲染、环境展示、复杂动作 | 中景/全景、慢推慢拉、摇移 | 代入情绪、听清台词、建立空间 | ⭐⭐⭐ 中（提示词要强约束） |
| **8–12 秒** | 长镜头、空镜、悬念结尾钩子 | 固定全景、极慢运镜、人物静止/无人 | 章节过渡、氛围、留钩子 | ⭐⭐⭐⭐ 高（走拼接） |

（表内分档为「时长×功能」匹配参考，非镜长口径；单镜总口径以文件头定案为准：**3–5s 主流、快节奏 2–3s**，卡点镜可下探 1–2s、对话/情绪镜可上探。）

**黄金配比（单集）【推测·未验证】**：快切镜（2–3s）约 **40%** + 主流叙事镜（3–5s）约 **50%** + 8 秒以上长镜约 **10%**。全用短镜=幻灯片快进疲劳；全用长镜=生成崩坏。快慢结合才有「呼吸感」。〔注记：原「1–4s/5–8s」分档表述已被 2026-10-31 镜长定案校正为新带宽，比例为内部经验值不变。〕

## 二、长镜头三法（8 秒以上不直接生成复杂内容）

1. **图生视频链式延长**（最稳）：先出高质量图 → 图生 4–5s → 取尾帧当下段首帧续 4–5s → 后期无缝拼接成 10–15s
2. **首尾帧控制**：指定首帧+尾帧画面，AI 补中间（适合固定机位、简单运镜如「从门推到窗」）
3. **内容降级**：非要直出长镜时内容必须极简——固定镜头、动作极简（静坐/站立/缓转头）、无复杂交互、背景简单

补充：5–8 秒镜生成不满意 → 拆成两个 3–4 秒镜，后期**匹配剪辑**（动作衔接）无缝拼。

## 三、分镜表扩展列（每镜标注，交生成与后期）

| 列 | 写什么 | 示例 |
|----|--------|------|
| 建议时长 | 数字 + 意图 | 「5 秒：前 2 秒静止，后 3 秒缓慢变化」 |
| 生成策略 | 直接文生 / 图生视频 / 首尾帧 / 链式拼接 | 「图生视频，首帧为静止壁画」 |
| 转场方式 | 硬切 / 叠化 / 淡出 / 闪白 / 声音先入 | 快切镜配硬切，情绪镜配淡出 |
| 音频提示 | 短音效 / 台词 / 环境音 | 「骨头断裂音效」「呼吸声加重」 |

音画对齐逻辑：1–4s 镜配单个短音效（好对齐）；5–8s 镜配台词/环境音（时长稳）；转场设计：快切镜结尾硬切/闪白，慢镜结尾淡出/叠化。**台词镜先产音频拿时长反锁分镜时长**（禁先视频后配音，时序必错位）；原生口型不准走「无台词表演+后期对口型」，详见 `../video-producer/references/video-consistency.md` §四。
口型/音频约束见 video-consistency（即梦对口型：图片模式 ≤15s / 视频模式 ≤36s / TTS 文案 ≤120 字）——分镜切分与音频反锁时长注意【社区教程·工具行为：it.sohu.com/907806985_120142897，2026-10】。

## 三·附、时长-质量机制【研究口径】（2026-10-31 批1 入库）

- **自回归误差滚雪球**【研究】：自回归逐段生成时，上一段的噪点/瑕疵被当作「既定事实」延续，误差累积（arXiv 2606.22370 "Towards Error-Free Long Video Generation"）。
- **联合打分陷阱**【研究】：RMD 论文（港中文+腾讯 AIPD，滚动边际蒸馏，https://www.techwalker.com/2026/1030/3204159.shtml ）——教师模型对「历史+当前」联合打分时，为保连贯会容忍历史瑕疵并延续到新片段（表现为颜色发绿发紫、边缘像素化、纹理马赛克化）；改为逐片段独立评分后，10s→60s 质量分 **84.68→84.52** 几乎不掉（Self Forcing 79.12→70.94）。
- **官方口径边界**【官方】：**官方从未承认「越长越差」**——30s 直出是官方卖点；官方仅有能力上限与预算警告（「指定时间段内容过多，会导致过度剪切或剧情遗漏，请注意时长安排的合理性」，2.5 指南）。「质量随时长退化」属研究/经验口径，写入交付时不得冒称官方。
- **实践口径**【经验】：生成侧单镜 5–10s 为甜点带（官方 2.5 素材表「主体音视频参考 5–10s 效果较好，更长稳定性下降需抽卡」间接支持）；超长叙事走延长任务/多镜拼接，不单镜拉满——与本表 §二 长镜头三法同源。

## 四、时长分配说明模板（随分镜表交付）

```
时长分配原则：
- 动作/冲击/特写镜 1–3 秒，提示词注明快节奏（fast motion / quick cut 语义，按后端方言写）
- 对话/情绪/展示镜 5–7 秒，提示词注明慢节奏（slow pace / extended shot 语义）
- 超过 8 秒的镜头必须拆段生成（三法见上），后期匹配剪辑拼接
- 每镜时长已标注，生成时严格遵循，禁止自行延长（长镜必漂移）
```

## 五、与既有规则的衔接

- **单集时长自动成型**不变：**正片 60–120 秒**（30–60 秒仅引流切片，不作正片集）（`shared/split-methodology.md`；2026-10-31 校准：原「30–120 秒/集」，30 秒档低于主流正片口径【社区共识·DramaSo/数艺社/知乎一致，平台审核规则明文未见】）——本表管**镜长分配**，不管集长
- **时间片制**不变：每时间片一个动作一个运镜；本表决定每镜开几个时间片、每片多长
- **绝对上限**：单镜 >15s 必须自动分段（后端方言硬限，`shared/backends.md`）
- **生成策略/转场/音频**写入交付格式的「导演阐述」段（LOCKED 字段契约不变）
