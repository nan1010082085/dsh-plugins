# 提示词格式规范（prompt-format）

> 规范「分镜块」里 `提示词` 字段怎么写。分镜块字段名逐字引用 `shared/output-formats.md` 第 2 节 LOCKED 契约：
> `镜号` / `时间片[]` / `六要素{主体外貌,动作,场景,光影,焦段运镜,音效}` / `转场交代?` / `素材映射[]` / `提示词`。
> 本文只讲写法；硬约束以 `shared/hard-gates.md` 为准，冲突时改本文。

## 一、六要素拼装顺序

`提示词` 按**时间片分段**，每段一个动作、一个运镜，段内六要素顺序固定：

```
[时间片] 主体外貌 → 动作 → 场景 → 光影 → 焦段运镜 → 音效
```

- **主体外貌**：固定长相锚点（发型/脸/服装套），与 assets.json 的角色资产同源；多人镜**逐人**写格位/外貌/动作/台词（双人镜漏挂对手是已犯事故，见 `shared/lessons.md` 第 13 条）。
- **动作**：每时间片只写**一个**主动作；情绪写生理细节（情绪可视化），不写心理描写。
- **场景**：写可行动空间与关键道具；场景资产必须纯空镜（有人场景不能用于出视频）。
- **光影**：按 `shared/lighting-system.md` 三层拼装——环境层一句 + 主光层一句 + 情绪层一句（共 2–3 句，写多必糊）；同场戏环境层+主光层全镜一致。
- **焦段运镜**：只用 `shared/camera-dictionary.md` 的**中文运镜名**（括注英文仅作对照，不进提示词）；每镜 1 条主运镜 + 至多 1 条景深/焦段修饰，速度（缓/匀速/急）必须写明。〔注记：「一镜一运镜」已被官方分代口径校正——2.0 单镜单运镜；2.5 时间戳段内单运镜、长镜头组合按段写清；1.0 可组合但按动作节拍分段，见 §二 镜头写法分代〕
- **音效**：与动作同步的环境声/动效声一句。

风格描述句（`shared/director-styles.md` 原句复制）写在**风格段**，与主体/场景/运镜段分离；一部剧锁 1 种，全镜同源。

## 二、时间片规则

- **格式**：`\d+[–-]\d+ 秒`（如 `0–3 秒`、`3–8 秒`），段首明写，机检②按此格式扫描。
- **每时间片一个动作、一个运镜**，禁止一句话堆 3 条以上运动。
- **单镜 >15s 自动分段**：拆成多个时间片或多个镜，不硬扛长镜头。
- **时间片连续不重叠**：0–3、3–8、8–12……不留空窗、不打架。
- **镜头细切**：每个动作/情绪转折切一刀，便于后期拼接；砍水戏，每刀都有信息量。
- 镜号全集连续编号；`时间片[]` 与 `提示词` 的段落一一对应。

### 镜头写法分代（官方，2026-10-31 批1 入库）

〔注记：sd2-pe「镜头顺序优先于绝对时间、禁写 0–3s」写法已被官方分代口径校正——2.5 时间戳是官方范式，引用按后端分代〕

- **Seedance 2.0**：只响应镜头序号——写「镜头1／镜头2」，**禁写绝对秒数**（官方 sd2-pe SKILL/2.0 指南）；单镜单运镜，禁止推拉摇移叠加（稳定性规则）。
- **Seedance 2.5**：响应**整数秒时间戳**，官方范式 `镜头 N｜0 秒 - 2 秒`，每镜头头字段带构图/景别/机位（官方 2.5 指南「与 2.0 差异点」+ 官方案例）；**时间戳区间必须连续**（`0-3…3-7…7-15`），不能跳段（`0-3…5-6` 禁止）（官方 2.5 指南）；不建议用时间戳控制频率/频次（官方 2.5 指南）；每个时间戳段内单运镜，长镜头多运镜组合必须按时间戳分段写清。
- **Seedance 1.0**：官方鼓励复杂运镜组合长镜头（官方示例：跟拍→上摇→360° 环绕→上移拉近），但必须按动作节拍分段写清。
- 来源：批1 报告 §①尾注/§②/§⑤-2~4（官方：sd2-pe SKILL、1.0/2.5 提示词指南、API 1520757）。

## 三、转场交代（强制项）

场景/时间变化的**进场镜**必填 `转场交代` 字段（可选字段名固定为「转场交代」），三件套缺一不可：

1. **时间**：旁白/字幕卡明写（「深夜，十一点」）；
2. **地点**：旁白/字幕卡明写（「城西写字楼天台」）；
3. **转场过渡句**：空间延续逻辑，**明写不硬切**（「镜头从楼下街道缓缓上升至天台」）；
4. **转场词写清触发点+方式**（Seedance 2.5 官方，2026-10-31 批1 入库）：时间点+方向/方式明写（官方示例：「第 5s 快速向左横移转场（向左擦除+自然叠化）」）。

硬切、转场无时空交代 = 零容忍直接失败（`shared/hard-gates.md` 零容忍清单；程序与教训见 `shared/lessons.md` 第 8 条，此处不复述全文）。

## 四、情绪可视化

心理/状态描写一律转生理细节，禁「他很害怕/她很伤心」式抽象词：

- 「她很悲伤」→ **「泪水滑落、嘴唇微颤，双手攥紧衣角」**
- 「他很害怕」→ **「手心出汗、后退一步、声音颤抖」**（与 `shared/split-methodology.md` 叙述→视听同源）
- 表情写解剖：眉、眼、嘴、神态收束（`shared/lessons.md` 第 4/12 条）。

## 五、禁废话词，用物理材质词

「塑料 AI 感」废话词一律禁用（机检③）：**4K / 8K / 杰作 / 超清晰 / 大师作 / wallpaper**。

质感改用**物理材质词**表达：

| 禁写 | 改写 |
|------|------|
| 8K 超清晰画质 | 发丝根根分明，风衣布面纹理可辨 |
| 大师作、杰作 | 雨水在皮肤上形成细密反光，霓虹在湿滑路面晕开 |
| wallpaper 壁纸感 | 空气中悬浮的尘埃颗粒可见，暗部保留织物褶皱细节 |

## 六、写实转 3D / cel-shaded

写实文字素材转三维动漫时，全剧统一在风格段明写 **「三维卡通渲染（cel-shading）」**（3D 都市动漫·卡通渲染，都市时尚质感），并注意：

- 风格描述句全剧同源（禁逐镜换风格——风格漂移是塌缩级事故）；
- 提示词中**不出现导演人名**，只写画面特征（`shared/director-styles.md` 使用规则 4）；
- 圆润造型/材质弹性等词按所选风格的描述句取用，不自创风格黑话。

## 七、参考图语义

- **默认多参考图语义**：多张参考图 = 多参考融合（角色/场景/氛围分挂），不默认首帧。
- 用户**明确说「当首帧」**才走首帧（first_last_frame）路径。
- video ref 只挂单人立绘当内容锚；接戏转场用首尾帧，绝不用整条视频做 ref（`shared/lessons.md` 第 5 条）。
- i2i 垫图会锚死构图，主体三视图转角度一律 t2i 文字控构图（`shared/lessons.md` 第 1 条）。
- **素材指代约定**（Seedance 2.5 官方 + BytePlus V1.0 运维注记，2026-10-31 批1 入库）：素材上传按**首次出场顺序**编号，图/音频索引成对（`img1-2 是人物 1，对应音频 1`）；禁止只在图片上写名字。

## 八、长度与交付形态

- **无字数上限**（2026-11-05 用户令：「不应该有这种红线」——原 ≤500 字红线废除；五道硬闸 1 本就写明「每镜不限字数但必须详细描写」，苗疆合集实证 seedance_2.5 正常出片 917–1288 字）。每镜细节 **≥250 字保底**、不限上限但必须详细描写。长度上限属后端方言（`shared/backends.md`），即梦/Seedance 无上限。
- `提示词` 必须以**代码块**交付，可直接复制即梦/Seedance 出片。
- 机检命令：`python3 tools/prompt_selfcheck.py [--mode image|video] <prompt_file> [ref ...]`（mode 默认 video=出视频；image=出图），或 `prompt_selfcheck.check(prompt, refs, mode=...)`。

## 九、出视频指令大结构（资产引用与四段式，2026-10-28 对照参考级案例修订）

> **真人实拍·多镜单视频变体**见 `live-action-instruction-spec.md`（2026-11-05 用户供参考级样本提炼）：规格块共享（摄影机/胶片/光线）+ 素材语义引用行 + 双格式镜头块 + 入点衔接，单条指令 917–1288 字实证，无字数上限。本节四段式是通用骨架，两者按剧种质感选用。

**文件头必含「本集故事背景」段（2026-10-30 用户令）**：从剧本对应集的故事背景/前提**逐字搬入**（世界状态/时间点/人物处境/本集故事前提）——剧本信息到分镜不得断链；虚拟导演的每一镜都必须知道自己在讲哪段故事。段落位置：文件头集纪律之前。


出视频指令用四段式大结构，**资产引用与文字描述双保险并存**。段内分行是工程化规格，不是散文：

```
【基础设定】
@资产名-版本-版本名：完整描述（形态/机制/服装逐件/材质/标志性特征；有表情机制的写明机制与切换音效）——引用≠免描述
@表情资产-状态名：本镜表情状态（如 @冷酷蓝色冷酷表情——表情是独立资产，按状态引用）
@场景资产-版本名：完整场景描述（时代风格锚 + 光线 + 氛围 + 死寂感/反差句）
声音：配乐/氛围音/同期声规则（如：不需要配乐，不要氛围音，仅保留同期声）

【氛围与画质】
风格核心：题材气质 + 美学体系锚（如「60年代复古科幻原子朋克美学」式时代美学词）+ 质感目标（超写实/极致逼真）+ 情绪目标（凸显…的刺激感、危机感、紧迫感）+ 禁项（杜绝游戏CG感、杜绝动作迟钝僵硬、禁止逻辑混乱）
视觉基调：画幅质感（变形宽荧幕电影质感）+ 机型镜头（IMAX 胶片摄影机 + Panavision C 系列镜头）+ 运镜质感（动态模糊标注/全程手持、轻微手持抖动、保持临场感）
色彩与影调：美学体系 + 色调对撞组（如复古暖橙+海盐蓝高对比）+ 胶片颗粒质感 + 低饱和度滤镜 + 光照（自然日光、强直射、自然光晕）+ 影调规则（明暗对比强烈、高光不过曝、暗部保留完整细节、明暗过渡自然、轻微柔光质感）

【画面内容】
分镜：单镜头一镜到底。｜或｜分镜N（时间码）
景别：近景。浅景深。长焦压缩空间。        ← 景别 + 光学特性独立成行
构图：前景为…处于画面中心线右侧，占画面二分之一面积；背景为…处于中心线左侧；拉伸透视，主体与延伸的街道形成动态对角。  ← 布局/占比/分割/透视工程化
运镜手法：固定机位，跟随拍摄主体。        ← 运镜独立成行
画面内容：叙事（演的是什么）＝**戏剧层驱动物理层**（2026-10-30 用户令）——戏剧层：这拍在讲什么故事、角色此刻要什么、情绪什么走向（戏魂，叙事的驱动）；物理层：可执行的逐拍动作链（动词化：掏→按→抛）+表演细节（表情/节奏/动作质感承载情绪，禁形容词堆砌）+台词。禁止只写动作物理不写戏（生硬死板=工程对了戏没了）。并强制织入两条（2026-10-30 三视频事故修复）：
          ①运动矢量——位移镜写死谁动/从哪到哪（画内方向）/什么速度/镜头动还是人动（镜头推拉与主体行进禁同向叠加：人走近则镜头固定，杜绝原地踏步与背景拉伸）；**位移镜默认运镜=同速跟拍/侧跟**（镜头与主体同向同速、相对静止——模型稳且画面有跟随感），固定机位只许四类：对话/特写/伏笔/时止，禁位移镜死机位（2026-10-30 用户令）；
          ②识别锚复现——当镜的道具特征（杆头灰道具乙布+贴纸这类）、服装特征、随身物状态（信物原色/浅红）必须在叙事里出现一次，防止道具漂移与服装漂移（基础设定段的双保险描述不删，叙事再锚一次）。
          ③写给模型，不写给读者（2026-10-30 用户令）——每句必须能被模型直接转成像素：一个可见事实或一个可执行动作。禁文学修辞（比喻/拟人/通感/情绪评论：「像…」「仿佛」「叹气」类），一律删或改写为物理事实（尺寸量化/位置/光线/动作/生理反应）。判定：这句话模型画不出来 = 删。
          ⑤双主体接触几何律（2026-10-30 用户令，治穿模——从画面内容根治，禁止靠反复重出试错）——凡背/抱/扶/拉手等双主体接触镜：a.接触点少而明确，写死手指落点与受力（「双手扣在她膝窝外侧」）；b.接触面轮廓分离句必备（「手指压在裤料表面，两手轮廓各自完整、与腿部不相交」）；c.接触区优先设计在镜头可见分离侧或被身体遮挡侧，禁正面无遮挡大接触面；d.接触镜动作减法（一镜只做接触本身，不再叠行走转向大动作）；e.姿态可画性优先——分镜设计时选 i2v 画得出的接触（撑肩/抓腕＞环颈贴面），写法上把「两个人接触」拆成「两个人各自完整、在某点相贴」。
          ⑥道具形态锁定律（2026-10-30 clip-review 回流，道具乙形态漂移实证）——a.道具形态写死三要素无歧义：材质（金属冷灰哑光/木质）＋颜色（禁紫/彩杆类歧义色，杆身写明无涂装）＋结构（杆头/贴纸/挂件逐件点名）；b.大面积暴露=形态漂移高发——分镜设计把道具暴露面收小（斜挂/竖持肩前小区域/遮挡侧），禁道具横穿大半画面；c.参考图预处理：道具图用「使用场景裁切图」（手持/在位）替白底特写，多角度挂载稀释漂移。
          ⑦提示词纯净律（2026-10-30 用户令）——指令只准含四类像素信息：人物/场景/道具的可见描述、动作与运动（织入白描）、镜头与光影、声音。禁入提示词：括号标注、标签前缀（「运动矢量：」「识别锚复现：」类）、名条与字幕卡（后期层元素，AI 画文字必出乱码，归后期清单）、素材映射行、复述锚点（「同镜N」类）、一切生产注记。

【声音设计】（2026-10-30 用户方案：声画绑定，不混写——画面内容负责「发生了什么」，声音设计负责「这一刻听到什么」，关键音效与画面动作/事件一一绑定）
台词：无／有（唯一出处，只在此段；带语气）。
旁白：无／有。音乐：无配乐写明。环境底噪：本镜要求写明（如「无持续氛围音」）。
动作声（绑定人物动作）：逐条「谁的动作→什么声→近远/持续或一次」——如：角色乙手臂收紧时，一次轻微衣料摩擦声；左腕微动时信物与腕骨极轻摩擦声。
事件声（绑定画面事件）：与画面物体事件同步——如：风卷塑料袋贴地刮过，与前景塑料袋动作同步；远处建筑倒塌闷响一声，背景层不压人物呼吸。
空间环境声：克制，只写要求。
三层纵深原则：近景=呼吸（情绪核心）｜中景=衣料/信物/道具细响（人物关系声）｜远景=环境事件声（灾难背景）。
画面内容里只轻提声音事件点（「衣料轻响」），声音参数（音量/频率/空间位置）只在本段。
```

**双保险铁律**：@资产引用只是锚定入口，**完整文字描述必须照写**。
**表情引用边界（2026-10-28 分镜审查实锤修复）**：@表情资产引用**只允许引用实际存在的表情资产状态**——表情表资产里的基础表情（平静/微笑/委屈/愤怒/震惊/含泪/冷漠…）或已建的表情资产；**自创情绪状态名（如「食言决绝」「心虚沉默」）不得加 @**——那是画面描述，写进画面内容即可，加 @= 指向不存在的资产，生成必挂。**道具同理**：道具（道具甲/信物/哑铃）走画面描述，不加 @（@ 只挂人物/场景/表情三类资产）。
**五段画面结构硬要求**：分镜/景别/构图/运镜手法/画面内容五段分行缺一不可——散文式揉成一段 = 打回（2026-10-28 用户对照参考级案例定）。

## 实战修正（每条来自出片事故或用户令，2026-10-30/31；织入叙事句子，不是标签）

1. 位移镜写死方向与谁动，禁镜头推拉与行进同向叠加——治倒退/原地踏步（实证）。
2. 双主体接触写「轮廓分离」句——治穿模（实证）。

## 十、官方硬约束与强制兜底包（2026-10-31 批1 入库，逐条标源）

1. **强制兜底包（每次输出必挂）**（**官方** sd2-pe SKILL/2.0 指南，批1 §①-7/§⑤-5）：出视频指令末尾必挂——
   - 画质包：`高清，细节丰富，电影质感，色彩自然，光影柔和`
   - 稳定包：`人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿`
   - 字幕兜底 ＋ 水印/Logo 兜底
   - 多人场景加**双胞胎兜底**（防同脸）；动漫/卡通场景加**风格锚定**（防漂移到写实）；多人正面动态加**强方位约束**。
2. **任务句式防误判**（**官方** sd2-pe/2.0 指南，批1 §①-3/§⑤-17）：编辑任务写「严格编辑 @视频N」、延长任务写「向后延长 @视频N」；**禁写「参考 @视频N」**（会被误判为参考任务）。
3. **断句防歧义＋主体绑定语法**（**官方** sd2-pe SKILL，批1 §①-2）：`@图片N` 不能紧接动词——「@图片1跑向」❌→「<主体1>@图片1 跑向」✅；主体绑定写 `<主体N>@图片N` 或「将 @图片N 中的[2-3 个稳定静态特征] 定义为 <主体N>」。
4. **Asset ID 屏蔽**（**官方** sd2-pe SKILL，批1 §①-2）：严禁 `[asset-xxx]` 裸写进动作描述。
5. **特殊字符规范**（**官方** sd2-pe/2.0 指南，批1 §①-10/§⑤-11）：音乐 `（）`、音效 `<>`、台词 `{}`、字幕/标题 `【】`；台词语种统一、小语种标注；多音字/生僻字改写为同音常用字防读错。
6. **眼睛发光兜底**（**官方** 2.5 指南 FAQ + BytePlus，批1 §⑤-10）：强烈情绪词会触发瞳孔发光，须最高优先级写「人物为正常人眼、不发光」，环境光只作用于面部轮廓。
7. **负向控制范围**（**官方** 2.5 指南，批1 §⑤-12）：只支持负向控制字幕与音频（`不要字幕`、`无 bgm`、`不要任何声音`），其余一律正向描述——要什么写什么，不写「不要 XX」。
