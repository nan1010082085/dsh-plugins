# 8 项强制自检清单（selfcheck-7，文件名沿用；2026-10-30 用户方案整合）

> 每个分镜块交付前逐镜执行。**任一项不过 = 打回改写，禁止带病交付。**
> 机检由 `tools/prompt_selfcheck.py`＋`tools/trust_audit.py` 执行；人检由导演逐条判读，结论写进交付。

1. **时间轴校验**（机检）：镜号时间码连续无重叠，总时长匹配（误差≤5%），**单镜 3–5s 主流、快节奏 2–3s**（社区 ASL 口径带源，批4 §2.2；卡点镜可下探 1–2s、对话镜可上探；对照 pacing-templates 景别×秒数表），后端官方时长上限分代（2.5=4–30s / 2.0=4–15s / 1.0=2–12s，官方）。〔注记：原「4–8s 为主」口径已被 2026-10-31 镜长定案校正，三方互指警告已解除，详见 shot-timing.md 文件头。〕
2. **结构完整性**（机检）：每镜四段式齐（基础设定/氛围与画质/画面内容/声音），画面内容五段分行完整，【画面内容】≥250 字。
3. **资产双保险**（机检）：每镜 @引用＋完整外形描述齐；素材映射表 ID 与 asset_registry.json 一致（字面校验）。
4. **画面纯净度**（机检）：提示词正文零括号标注/标签句/画面内文字（名条字幕卡归后期清单）/素材映射行/复述锚点/文学修辞。
5. **硬规则**（机检+人检）：时止次数/时长合规；关键道具状态跨镜连续（示例占位：状态词属剧内数据，住 assets.json/Notion，勿入 skill（2026-10-31 纪律））；运动矢量写死无同向叠加；台词唯一出处（只在【声音】段）。
6. **识别锚复现**（机检）：每镜至少一个核心识别锚（道具特征锚占位/关键道具状态/服装特征）自然出现于叙事。（示例占位：道具特征名属剧内数据，住 assets.json/Notion，勿入 skill（2026-10-31 纪律））
7. **剧情落点**（人检）：名场面/钩子/伏笔全部对应指定镜头，看镜内有落点；戏剧层在（这拍在讲什么/角色要什么/情绪走向）。
8. **后期项校验**（机检）：名条/字幕卡/卡点音效全部在后期清单，提示词正文零残留。

判读记录格式：`自检：机检 1–6/8 全过；人检 7 剧情落点 过——理由；人检 5 硬规则 过——理由。`
