# 节奏与策略模板库（pacing-templates，2026-10-30 用户方案）

## 一、漫剧节奏方法论（静态画面+镜头运动+声音驱动）

**景别×秒数对照**（成片剪辑口径；生成侧不足 4s 按 4s 出后裁）：
**镜长统一口径（2026-10-31 批1 定案，用户已批；三方互指警告已解除）**：**单镜 3–5s 主流、快节奏 2–3s**（社区 ASL 口径带源，批4 §2.2）＋ 后端官方时长上限分代（2.5=4–30s / 2.0=4–15s / 1.0=2–12s，官方）。〔注记：原「1.5–4s」口径已被镜长定案校正，详见 shot-timing.md 文件头。〕
（下表为景别内剪辑参考秒数，属快节奏带细化：卡点/快切镜可下探 1–2s、对话/情绪镜可上探——批4 §2.2 校准结论；单镜总口径以上方定案为准。）

| 景别 | 建议秒数 | 用途 |
|------|---------|------|
| 大全景/远景 | 3–4s | 展示环境，给够时间看景 |
| 中景 | 2–3s | 人物动作、互动 |
| 近景/特写 | 1.5–2s | 表情、细节、伏笔 |
| 大特写（眼/手/纹路） | 2–3s | 关键悬念点，要「盯」一下 |

**时长分配原则**：信息交代段 2–3s/镜；情绪积累段 1–2s/镜快切；高潮爆发段突然变「松」3–5s/镜长镜+慢推拉。
**运镜呼吸感**：缓慢推进=压抑/聚焦；快速横移=紧张/逃离/时间流逝；极慢旋转=超自然/神性；固定镜头=憋闷窒息。
**黄金法则**：①一镜一目的（一镜只传递一个信息）②声音是半条命（回声/心跳/静音写死在分镜）③快切≠紧张，真正窒息的是「该切不切」的长镜④特效镜（神纹/时止/定格）舍得给 2–5s。

## 二、剧情策略模板（四套，生成时自动匹配）

### 1. 灾难建立模板
全景起→中景跟→特写落点；慢节奏；固定机位/缓推为主；环境音先行。

### 2. 惊悚悬疑模板
快切+固定机位；大特写+浅景深；声音前置转场；「该切不切」的固定长镜制造煎熬；镜头运动克制（微颤多于运动）。

### 3. 名场面模板
缓推+升格（慢动作）；近景转全景拉开展示；声音先抽后炸（静音 2–3 秒再轰响）；奇观镜给足 2–5s。

### 4. 温情日常模板
侧跟+中近景；呼吸式微晃运镜（稳定器承载，仅呼吸浮动）；节奏平缓；台词驱动；情感符号绑定动作节点收尾（示例占位：符号/道具名属剧内数据，住 assets.json/Notion，勿入 skill（2026-10-31 纪律））。
