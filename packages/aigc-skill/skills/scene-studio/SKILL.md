# scene-studio（场景出图 · 空镜与光影锁定）

把剧本场景变成**同场连贯**的空镜图片资产：一场景一主图（必要时出变体），光影锁定全镜共用。场景转场连贯是留存三主轴之一——同场景多镜不跳戏、换场有交代，都靠这套资产打底。

## 何时使用

- 剧本条目产出后，要出场景图/空镜/场景变体
- 分镜块 `素材映射[]` 点名了场景资产需要建/补/重制
- 用户提到：场景出图 / 空镜 / 场景图 / 背景图 / 场景一致性

## 流程

1. **读剧本建场景清单**：从剧本条目 `场景节拍[]` 与分镜块提取场景，按 `references/scene-asset-system.md` §一 登记 scenes[]（含 `光影锁定`） 每景建**场景设定卡**（行业字段，总纲见 `shared/manhua-production-standard.md` §四）：**固定物件清单**（道具不能凭空消失）、**天气/时段多版本**（白天/黄昏/雨夜/夜晚，常驻场景多版本复用）、16:9 横版构图机位、**场景分层**（远景/中景/前景遮挡——前景模糊做景深）。
2. **出图前置调研（固定工序）**：执行 `shared/pre-gen-research.md` 四步（与人物 skill 同工序）
3. **场景主图（t2i）+ 镜头变体**：按 `references/scene-library.md` 选类别配方（构图/道具/光影/色调）；指令格式按 `references/scene-shot-light.md`——**镜头前缀三选一**（全景默认/中景对话/特写背景），分镜需要时同场景+同光影只换前缀出变体；**光影配套防脱节**（时段型预设：白天顺光柔和/黄昏暖侧逆光/夜单一暖顶光 + 「和角色光影匹配」）；同场景全剧一主图+按需变体
4. **场景变体（i2i 挂主图）**：剧情需要场景变化（布置/昼夜）时出变体——同机位同光影只改道具层
5. **交付与对账**：写入 assets.json scenes[]（LOCKED 字段逐字），与分镜块 `素材映射[]` 对账——场景必挂

## 硬闸与自检

- **空镜铁律**：画面绝对无人物/人群/剪影/手——有人场景不能用于出视频，重出
- **贴人五条**（`references/scene-shot-light.md`）：无人物写死/中心区域空旷预留人物位置/无文字标识水印/风格锁死/低饱和度弱化背景不抢戏
- **光影配套**：场景光影与角色设定卡（柔和影棚柔光）匹配——禁杂乱多光源/强硬阴影/大面积刺眼光斑；光影锁定值细化但不得违反光质预设
- **光影锁定**：环境层+主光层写入 `光影锁定` 字段（`shared/lighting-system.md` 三层），情绪层留给分镜逐镜微调；同场景所有镜头共用
- **广告闸**：场景内商品/陈设/灯牌「素色无品牌+无文字无商标」，过 `tools/brand_scan.py`
- **花钱门**：扣积分出图走 `tools/credit_gate.py`
- **调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）**：`watermark=false` 必设（默认打「AI 生成」水印）、返回 URL 24h 失效即时转存、prompt 中文 ≤300 字——全参数见 `references/scene-shot-light.md` §五
- **验收清单**（`scene-library.md` §4）逐张过：无人物/光影一致/可行动空间/门向与道具连续性
- 一枪一停、重制不夹带（`shared/hard-gates.md`）

## 产出与格式

- **assets.json scenes[]**：字段名逐字 `shared/output-formats.md` §3 LOCKED 契约（`{名, image, 光影锁定}`）
- **场景生图指令**：五段式组装（`shared/prompt-formula.md` §四），代码块交付，按目标后端方言
- **对账表**：场景 × 出镜镜头 × 挂载节点，交 `shot-qa` 素材校验
