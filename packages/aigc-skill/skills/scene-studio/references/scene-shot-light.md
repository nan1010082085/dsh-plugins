# 场景镜头变体 × 光影配套 × 贴人规则（2026-10-28 用户定）

> 核心原则：**场景与角色风格统一、方便角色贴入、光影可控、构图适配短剧镜头**。背景是衬托角色的，不抢戏。

## 一、按镜头类型微调（同一场景一图多用）

同一场景出全景/中景/特写背景，**前缀只是引导，变体必须连正文一起改**（2026-10-28 xyq 实测教训：只换前缀=三张几乎一模一样，白烧积分——正文的描述主体与构图锁才是约束主力）：

| 镜头类型 | 用途 | 前缀 | **正文必须同步改** |
|---------|------|------|------------------|
| **全景** | 交代环境（默认主图） | `大远景全景，广阔空间，` | 全要素描述 + 构图锁「广角纵深」 |
| **中景** | 人物对话主力镜头 | `中景构图，视觉焦点在画面中间，适合半身人物，` | **删远景元素、只保留中段元素**，构图锁改「中景平视、主体占画面三分之二、背景收窄」 |
| **特写背景** | 道具、反应镜头 | `局部特写背景，虚化环境，聚焦小物件，` | **主体改写为单件小物放大**（指定物件），其余全部虚化，构图锁改「特写构图、浅景深」 |

出图规则：一场景默认出**全景主图**；变体=同场景**同光影同风格**+改写后的描述主体/构图锁；**验收必查三张互不重复**（构图/景别/取景范围肉眼可辨），重复即按上表重写正文重出。

## 二、光影配套规则（防止角色和场景「脱节」）

角色设定卡=柔和均匀影棚柔光；场景光影必须**与角色光影匹配**，否则贴人必违和。

| 时段型 | 光影预设 |
|--------|---------|
| 白天外景 | `顺光/侧顺光，柔和日光，阴影边缘柔和` |
| 黄昏戏 | `暖金色侧逆光，轮廓光，阴影偏暖棕` |
| 室内夜晚 | `主光源单一，暖顶光，暗部不要死黑` |

- **固定光影模板（全场景复用）**：`柔和侧顺光，阴影过渡自然，环境光统一，和角色光影匹配`
- **避免**：杂乱多光源、强硬阴影、大面积刺眼光斑
- 每场景的「光影锁定值」在预设基础上细化（光源位置/色温/时段），但不得违反预设的光质约束（柔和/单一光源/暗部不死黑）

## 三、贴人避坑清单（逐条写死进指令）

1. **禁止 AI 自动生成路人**：`画面中不要任何人物`（空镜铁律的强化句）
2. **中心留空贴人**：`画面中心区域空旷，无遮挡，预留人物位置`（大树/柱子/杂物禁挡中心）
3. **无字**：`画面无任何文字、标识、水印`（含 logo/涂鸦）
4. **风格锁死**：全程带风格锁段（一剧一风格，禁一会二次元一会油画）
5. **不抢戏**：`低饱和度，弱化背景细节`（背景是衬托角色的）

## 四、场景指令模板（五段式场景版）

```
〔风格锁段〕。
〔镜头前缀：全景/中景/特写三选一〕〔场景描述：时代锚/空间结构/固定物件清单/材质细节〕。
〔光影预设句（按时段型）+ 光影锁定值细化〕。
氛围：〔反差句/情绪基调〕。画面中不要任何人物，画面中心区域空旷，无遮挡，预留人物位置。
构图锁：〔机位/纵深〕，画面无任何文字、标识、水印，低饱和度，弱化背景细节，和角色光影匹配。
```

## 五、即梦/Seedream 调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）

调用生成前逐条过（风格段/排除段方言仍按 `shared/backends.md`）：

- **prompt 中文 ≤300 字（英文 ≤600 词）**：官方明示「字数过多信息容易分散，模型可能因此忽略细节……造成图片缺失部分元素」——超长砍形容词保要素
- **`watermark=false` 必设**：默认 true 会在右下角打「AI 生成」水印，出片素材一律显式关闭
- **返回 URL 24h 失效**：生成后立即下载转存入库，禁止只存 URL
- **无 seed 参数（官方否定结论）**：不承诺复现；「锁参数」=锁 prompt+参考图+size，重生成必抽卡
- **无 negative_prompt 参数（官方否定结论）**：排除意图写成 prompt 正向排除句（模板「画面中不要任何人物……无文字、标识、水印」即此写法）
- **无 strength/重绘幅度参数**：变体改动程度用「保持 X 不变，将 Y 改为 Z」指令句控制（见 §一/scene-asset-system §三）
- **多参考图按「图1/图2」序号引用输入顺序**（官方示例：「将图1的服装换为图2的服装」）；Seedream 4.0/4.5/5.0 lite ≤14 张、5.0 pro/flash ≤10 张
- **size 推荐「档位+比例描述」**：成片 16:9 空镜用 2K 档映射值 **2848x1600**（官方表）；成本 ∝ 像素数（4K 档≈2K 档 4 倍），空镜主图按需选档
- **组图模式（sequential_image_generation）**官方定位=漫画分镜/故事板一组关联图——正对 §一 的全景/中景/特写变体组：可一次生成，prompt 必须写明数量与逐张内容（「生成3张……图1→图3」句式），参考图+生成图 ≤15；不走组图时仍按 §一 逐张改正文出
