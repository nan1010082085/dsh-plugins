# 场景类别库（十类高频场景 × 构图/道具/光影/色调配方）

> 每类模板通用结构：`〔风格句〕。〔类别配方〕。空镜，画面无人物。构图锁：固定机位标准构图，无文字无品牌标识。〔负面段〕`。五段式组装见 `shared/prompt-formula.md` §四。
> 注记（官方：火山方舟《图片生成 API》2026-10-14）：〔负面段〕在即梦/Seedream=正向排除句（API 无 negative_prompt 参数）；SD 系负面框后端才放负面词。模板内「无文字无品牌标识」句即正向排除句写法。

| 类别 | 构图与必备道具 | 光影/色调 |
|------|--------------|----------|
| **粉系直播间** | 电脑桌居中、补光灯/环形灯、玩偶墙、声卡、手机支架、粉墙 | 暖粉主调，屏幕冷光+补光灯双光源，柔光无阴影死角 |
| **客厅（家庭）** | 沙发+茶几+电视墙，生活杂物适度（水杯/遥控器），可选落地窗 | 暖白日光或晚间暖黄顶灯，居家低对比 |
| **卧室** | 床+床头柜+台灯+衣柜一角，床品柔软质感 | 台灯暖光主导，夜景小夜灯补光，私密柔和 |
| **厨房/餐厅** | 灶台/餐桌+餐具，可加蒸汽感 | 窗光+暖顶灯，食物区高光，烟火气暖调 |
| **玄关/门口** | 门+鞋柜+挂衣钩，门口纵深构图 | 门外冷光与室内暖光对比，明暗交界 |
| **街道夜景** | 霓虹灯牌（无文字灯箱）、路灯、店铺橱窗剪影、湿地面反光 | 霓虹多彩+路灯暖橙，高对比夜色 |
| **车内** | 仪表盘/方向盘/车窗外景流动虚化 | 日间前侧光或夜间仪表盘冷光+路灯扫过 |
| **校园/教室** | 课桌排布+黑板（纯色无字）+窗外绿植 | 明亮窗光，清爽高调，青春感 |
| **办公室** | 工位隔断+显示器（屏保纯色）+文件架 | 冷白日光灯，低饱和职业感 |
| **咖啡/休闲店** | 吧台+高脚凳+暖灯串+绿植 | 暖棕木色，焦糖调，松弛感 |

**自定义场景**：先定最近似类别的基调（构图骨架+光影配方）再替换道具；光影沿用该类别配方并写入 `光影锁定`。

## 双语示例（即梦中文 / 英文后端）

中文（日常室内）：
> 〔风格句〕。现代简约咖啡馆靠窗座位，午后阳光透过木窗洒在桌面，一台笔记本电脑和一杯拿铁，绿植点缀，背景虚化。空镜，画面无人物。构图锁：固定机位，中景平视，无文字无品牌标识。〔负面段〕

英文（赛博朋克夜街，供 MJ/Flux 等后端）：
> 〔Style sentence〕. A rainy futuristic alleyway at night, wet asphalt reflecting neon pink and cyan lights, volumetric fog, no people, wide shot, cinematic composition, hyper-detailed. No text, no logos, no brand signs.
