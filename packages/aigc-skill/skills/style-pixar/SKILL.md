# style-pixar（皮克斯质感 · 风格段）

剧目风格锁为「皮克斯质感」时的风格段出口。核心是四件套：圆润比例 + 夸张表情 + SSS 材质 + 电影级布光。风格段 = 风格锁句 + 高效组合词组 + 后端画质/负面词尾巴。

## 何时使用

- 剧目风格锁为「皮克斯质感 / 3D 动画电影感」时，所有出图/出片提示词取本风格段
- 用户问：皮克斯风 / Pixar style / 3D 动画质感提示词怎么写
- 新剧立项定风格、或人物三视图/场景空镜/分镜成片需要统一风格段

## 流程

1. **确认风格锁**：一部剧只锁 1 种风格，全剧不换（与 `shared/director-styles.md` 全剧基调对齐）
2. **取风格段**：从 `references/style-profile.md` 取「风格锁模板」（中/英各一版）+「高效组合」四件套词组，组装风格段；表情词写具体情绪（curious/joyful）不写只 cute
3. **按后端调方言**：画质词/负面词按 `shared/backends.md` 与 style-profile「负面词与画质词策略」分流——全平台删 masterpiece/8k，换 SSS/材质/布光词
4. **总装**：风格段嵌入五段式组装（`shared/prompt-formula.md` §四），与人物锚点段、场景锚点段拼接；一图一变量，不一次改表情+服装+场景
5. **翻车点自检**：对照 style-profile「翻车点与对策」逐条过，重点查塑料假人感与角色名禁令

## 硬闸与自检

- **禁写实词混入 cel 系**：photorealistic / skin pores / 85mm / DSLR 不进风格段——冲掉动画感（研究 §7 修正 1）
- **禁知名角色名/受保护角色**：风格描述≠复制角色，禁写皮克斯/迪士尼具体角色名与 IP 名（研究 §4-3 版权避坑）
- **画质词按后端分流**：禁统一挂 8k/RAW/masterpiece——masterpiece 在 SDXL 把图拉向画廊绘画、Flux/即梦/MJ 无效【社区实证·Promgrammer】（研究 §3）
- **风格污染警告**：赛博霓虹、写实电商产品图质感不进本风格段（写实产品图用皮克斯风会「卡通化」产品）；一剧一风格
- **出图前置调研**：新疑问先走 `shared/pre-gen-research.md` 四步，结论回写 style-profile.md

## 产出与格式

- **产出 = 风格段文本**（中文版 + 英文版，可直接嵌入五段式组装的风格位）
- 风格段固定三件：风格锁句（整段复制）+ 高效组合词组（四件套按需摘取）+ 后端画质/负面词尾巴
- **沉淀规则**：调研/实战新发现回写 `references/style-profile.md`，标注来源；未查证处标【推测】
