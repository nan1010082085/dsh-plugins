# video-producer（出视频执行 · 单镜隔离与容错）

出片的执行层：把「分镜块 + assets.json」变成可用视频素材。核心哲学是**把不稳定变量提前约束**——所有不确定（变脸/服装串/肢体崩/画风割裂）都在流程里兜底，不靠 AI 随机发挥。上游 `shot-qa` 过检后才进本 skill；本 skill 不改创作内容。

## 何时使用

- 分镜块 + 素材资产过完 `shot-qa` 三道闸，要实际生成视频
- 出片失败要重生成、崩坏镜要兜底
- 用户问：怎么出视频 / 怎么稳定出片 / 为什么老变脸 / 口型对不上

## 流程

（五步，按序执行）

1. **前置资产校验（预检）**：三视图线条清晰无歧义、服装边界/配饰轮廓明确、同角色不同套五官完全统一；场景图与人物美术风格对齐（三视图画风≠视频写实化，必崩）；可选：三视图+定妆照训练角色 LoRA / IP-Adapter 权重（比纯传参考图强一档）
2. **分镜拆解 + 生成包组装**：一镜一生成包（分镜编号 + 角色参考卡 + 场景参考 + 提示词 + 负面词）；**禁止批量连跑多个独立视频**——批量连跑一崩全崩。**多镜单视频例外（2026-11-05 用户令）**：为保镜头间连贯、治切换不流畅，**允许多个分镜合并进一条视频**生成——一条指令内「分镜N（时间码）」逐镜时间码连续、每镜「入点与动作」衔接上镜末态（写法见 storyboard-director `references/live-action-instruction-spec.md`）。边界：禁的是「一次任务连跑多个**独立**视频」，不禁「**单条**视频内多镜时间码」；合并镜按时间码组打包（一组一生成包），失败按时间码段归因重生成
3. **小批量试产（测试镜锁参）**：先跑 2–3 个代表性镜（特写/中景/带动作各一），验证三件事：变脸没、服装跑没、运镜正常没；**通过后固化提示词/参考图/参数，批量期禁止再改**（详见 `references/production-workflow.md` §三）
4. **批量生成 + 素材入库**：每镜输出**按有序命名规范**单独存放（见下方「产出与格式」素材库命名）；标注成功/失败与失败原因（变脸/肢体崩/场景错/服装串）；每镜预留 2 版备选，预算按 **30% 重生成余量**报价（花钱门）（30% 数值=【经验·内部】——AI 视频重生成失败率无公开统计，纯内部预算经验值，批4 核验 2026-10-31）
5. **后期统一收口**（剪映工艺包，行业标准见 `shared/manhua-production-standard.md` §七）：**台词气泡**（统一样式、底部靠边不挡脸、字号固定、跟随卡点）；**音效三分层**（基础环境音低量底音／情绪 BGM 段落制切大场景才换／提示音效含出场叮）＋音效不盖台词铁律；**整片一个 LUT**；**转场词典**（对话硬切、时间跳转/回忆闪白黑场）；**静态漫剧模式（主）**：单镜 2–4s 静态图+缓慢缩放 0.8–1.5 倍极慢速/缓慢横移（缩放倍率 0.8–1.5=【经验·内部】——查无行业标准/教程给出该区间，内部经验值，批4 核验 2026-10-31），动态感来自镜头缓移与转场不靠逐帧动画；衔接处淡入淡出/切镜掩盖帧间闪烁；台词音效字幕转场全部后期叠加；**首出场名条**（定格卡片+名字条+叮音效，每角色仅一次，规范见 `references/first-appearance-nametag.md`）；**崩坏镜标记后单独重生成该镜**，不整段重做

## 硬闸与自检

- **出片五律（2026-10-29 用户令，最高优先级，详见 `shared/hard-gates.md` §出片五律）**：①分镜四段式逐字节传递禁压缩改写（超上限=回 Notion 设计变更）②付费前必过 `tools/shot_gate.py` 全闸+Notion 状态=生成中审查 ③每镜 @素材真实绑定到该锁名登记的画布素材（状态变体按镜内状态选对）④素材-分镜数据一致、按资源 ID 逐个核对防 @取错 ⑤数据流转全走 Notion（本地↔Notion 内容列 SHA 级一致才准出片）。任一 FAIL 拒绝生成
- **出片指令唯一来源（2026-11-10 用户令，TEST T4 判 0 分教训）**：出视频提示词**只能**按 storyboard-director `references/prompt-format.md §九` 四段式镜块产出（基础设定/氛围与画质/画面内容/声音 + 画面五段分行 + @锁名双保险 + 官方兜底包），**禁止手写散文式提示词**、禁止凭观感自创格式；`prompt_selfcheck.py` 机检通过 ≠ 按 skill 走（机检只查合规底线，不查四段式/五律/模型锁）——出片前逐条对 §九 自查结构，缺项即回炉重写
- **画幅规格（2026-10-28 用户终定）**：出图与出视频**统一 16:9 横版**（生成参数 `--ratio 16:9`；竖版致素材生成不全）
- **出片模型（2026-10-29 用户定）**：即梦出片一律 `seedance_2.0_fast_vip`；其他模型禁用于产品生成，比价只准 quote 不准 run
- **花钱门**：所有生成含重生成余量一并报价（报价→用户批→跑）；重生成也走闸，禁止「再跑一枪试试」
- **单镜隔离**：一镜一包一生成，禁批量连跑多个独立视频；多镜单视频（单条指令内多镜时间码）允许且推荐用于连贯戏（2026-11-05 用户令，见流程 2）
- **参考图用量**（`references/video-consistency.md` §一）：每角色单镜 ≤ 正面主参考 1 张 + 可选侧视 1 张；禁多张三视图塞同一视频 prompt（参考冲突画面崩）；总 ref 数遵守后端上限（默认 ≤9）
- **镜头约束话术必带**：每镜提示词附固定一致性锁句（`video-consistency.md` §二模板）+ **官方兜底包**（画质包/稳定包/字幕兜底/水印·Logo 兜底每镜必挂，多人加双胞胎兜底、眼睛发光兜底，`video-consistency.md` §二【官方：火山 sd2-pe SKILL】）
- **动作减法**：单镜 1 个核心动作（与分镜创作的「一时间片一动作」同源）；复杂连续动作拆镜
- **运镜保守**：固定机位/慢推慢拉优先；禁高速环绕、大幅度摇镜、强动态模糊+特写组合（人脸必漂）
- **口型与音频**（`video-consistency.md` §四）：台词镜**先产音频拿时长反锁分镜时长**，禁先视频后配音；原生口型不准走「无台词表演画面+后期对口型」或口型驱动+低运镜幅度；即梦对口型硬约束=清晰正脸、图片模式成片 ≤15s、视频模式 ≤36s、TTS 文案 ≤120 字【社区教程·工具行为：it.sohu.com，2026-10】，音画/口型一致性=平台官方违规红线【官方：视频号 5.11.4】
- 一枪一停、原节点重跑、验真只认新产物（`shared/hard-gates.md`）

## 产出与格式

- **生成包清单**：镜号 × 参考图集 × 提示词 × 负面词 × 生成参数（对应分镜块 LOCKED 字段，不新增契约字段）
- **素材库**：分镜出片素材**有序命名（2026-11-10 用户令）**：`NNN_<分镜描述>_xx.mp4`——NNN=三位数集内出片序号（001 起，按分镜顺序，导入剪辑软件后天然按剧情时间排序），`<分镜描述>`=该镜一句话内容关键词（如 回廊拂柱），`xx`=镜号/版本标识（如 镜3 / _v2）；示例 `001_回廊拂柱_镜1.mp4`、`002_木窗回望_镜2.mp4`。目录可保留 `分镜/NNN/`，但**文件名必须自带序号+描述**，禁止只用 `第NNN集·镜N.mp4` 这类无描述命名 + 成功/失败标注 + 失败归因表
- **试产锁参记录**：测试镜用的参数集（批量期只准照抄）
- **收口清单**：调色基线 / 转场处理 / 音频轨 / 崩坏镜重生成列表
- 下游：成片交付；崩坏镜回本 skill 步骤 5 单独重跑

- **对时机检（2026-11-05 成片实测）**：出片前时间覆盖总长必须=生成时长 ±0.5s，过 `prompt_selfcheck --duration N` ⑦。
