# 视频层一致性约束（参考图用量 · 约束话术 · 口型音频）

> 视频生成的一致性比生图更脆（逐帧误差累积）。三视图在视频层的身份是**角色身份锚点**——用法和生图不同，本文是视频层专用规则。

## 一、三视图/参考图的视频用法

1. **统一角色 ID 命名**：所有三视图/立绘/参考图带唯一 ID（`Char_A_基础服_正/侧/背`、`Char_A_骑士服_正/侧/背`）；分镜明确标注本镜用哪套服装，**禁止 AI 自动换装**
2. **参考图用量上限**：单镜每角色 ≤ **1 张正面主参考 + 可选 1 张侧视辅助**——多张三视图塞同一视频 prompt = 参考冲突、画面崩坏
3. **两层资产分工**：【基础形象三视图】管脸型/五官/头身比/骨骼（不动）；【服装三视图】只换服饰，五官发色体型参数固定
4. **角色参考卡（推荐）**：正面大图为主 + 侧背小图拼一张合成卡，专供图生视频/IP-Adapter/角色 LoRA（建法见 `../character-studio/references/character-prompts.md`）
5. 同场景多镜共用同一场景参考 + 光影四件套逐镜复制（`shared/prompt-formula.md` §二）
6. **双保险铁律**：@资产引用 ≠ 免描述——引用素材后必须紧跟完整文字描述（身形/五官/服装逐件/材质），只写引用不写描述 = 信息不足照样崩（出视频指令四段式见 `../storyboard-director/references/prompt-format.md` §九）

## 二、镜头约束话术（每镜提示词必带，固定句式）

```
强制保持角色五官、脸型、发色、身高不变；严格使用【XX 服装套名】，
服装款式、配饰与服装三视图一致，不新增、不删减配饰。
```

配套视频负面黑名单（无负面通道的后端正向改写，见 `shared/backends.md`）：

```
五官扭曲、肢体畸形、多余手指、服装错乱、角色变脸、画面闪烁、帧间漂移
```

### 官方兜底包（2026-10-31 入库，每镜必挂）

【官方：火山 sd2-pe SKILL.md（arkdocs.tos-cn-beijing.volces.com/files/video-generation/SKILL.md）+ Seedance 2.5 指南 FAQ；批1 ⑤5/⑤10】每次输出必挂的强制兜底：

```
画质包：高清，细节丰富，电影质感，色彩自然，光影柔和
稳定包：人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿
字幕兜底 / 水印·Logo 兜底：画面干净、无随机字幕、无水印无 Logo 字样
```

- **多人场景**加双胞胎兜底（防两人长成一张脸）；**动漫场景**加风格锚定（防漂移到写实）；**多人正面动态**加强方位约束。
- **眼睛发光兜底**（2.5 指南 FAQ+BytePlus）：强烈情绪词会触发瞳孔发光，须最高优先级写「人物为正常人眼、不发光」，环境光只作用于面部轮廓。
- 水印/Logo 兜底=防画面里长出杂牌水印/Logo（与品牌三层禁同向）；发布成品的 **AI 生成显式标识义务是另一件事**，见 `shared/hard-gates.md` 第 10 节（标识由发布方加，不是模型烙水印）。

## 三、运镜与动作的安全边界（视频层）

- 固定机位、慢推慢拉优先；**禁高速环绕、大幅度摇镜**（人脸必漂）
- 动态模糊/强运动镜头**禁止配人物特写**
- 单镜 1 个核心动作；「转身、抬手、弯腰、转头同时说话」级复合动作必拆
- 特写镜尽量少动；说话镜降低运镜幅度（运动越大口型越乱）

## 四、口型与音频策略

- **台词镜先产音频 → 拿音频时长反锁分镜时长**（禁先视频后配音，时序必错位）；音频轨进 `../storyboard-director/references/shot-timing.md` 的音频提示列
- AI 原生口型不准的两种走法：
  1. **优先**：生成无台词表演画面，后期用数字人工具对口型
  2. 工具自带口型驱动：分镜单独标注台词文本 + 降低运镜幅度
- 台词文本逐字来自剧本（零压缩），口型层不改词

### 即梦对口型工具约束（2026-10-31 入库，出片前置检查）

【社区教程·工具行为实测：it.sohu.com/907806985_120142897（三郎教程，2026-10 访问）；即梦未见官方公开网页文档——工具行为口径，官方文档补齐后按官方校准】

- **清晰正脸**是硬前提（真人或动漫图/视频均可，正脸不清晰口型必崩）
- 三种模式上限：**大师/快速=仅图片输入，成片 ≤15s**；**基础=仅视频输入，成片 ≤36s**——超上限必须切段，直接影响单镜台词量与分镜切分（分镜切分写法侧 →`storyboard-director` 域）
- 音频两条路：上传音频 or **即梦 TTS 合成（文案 ≤120 字）**；积分随音频时长/文字量计
- **先产音频反锁时长的工具层依据**：主流 TTS 是「文本→音频」单向生成，音频时长由文本量决定【官方：火山引擎豆包语音文档 volcengine.com/docs/6561/1594356】——反锁时长在工具层自然成立
- **验收底线=平台官方红线**：「视频配音与画面不相关」是违规项，音画/口型一致性不只是美观问题【官方：微信视频号运营规范 5.11.4】
- 空白注记（查不到，明说）：音素-视位对齐度等口型量化验收标准**无公开行业标准**（批4 ⑧8），验收以 5.11.4 官方红线 + 人审口型观感为准

## 五、批量期纪律

- 试产锁参后**参数/参考图组合/提示词结构三不改**
- 每镜 2 版备选（预算 30% 重生成余量——数值=【经验·内部】，无公开失败率统计，批4 核验 2026-10-31）
- 失败归因四分类入库：变脸 / 肢体崩 / 场景错 / 服装串——重生成前先归因，改对应层（人物→character-studio、场景→scene-studio、运镜→storyboard-director），不是盲目再跑
