# 首出场名条规范（角色首次亮相定格卡片 · 剪映工艺）

> 2026-10-28 用户定。漫剧标准工艺：人物**第一次出场**时画面定格 + 角色名标签。分镜层负责**标注**（哪一镜谁首出场），后期层负责**制作**（剪映定格卡片）。全剧每人只做一次，后面同人不再重复。
>
> **参数注记（2026-10-31 批4 核验·被校正条目留注记）**：本文量化参数（名条停留 0.8–1.5 秒、卡点同步等）=【经验·内部：2026-10-28 用户定值，卡点/定格节奏无量化权威资料，卡点剪辑属社区教程生态实践（B 站/抖音）】——数值与工序均为用户令（U 级），注记仅标明无行业量化依据，**不改任何用户定内容**。

## 一、制作工序（剪映 / CapCut 标准五步）

1. **定格**：人物首次出现的那一帧**定格**（剪映：选中素材 → 定格，生成静帧图片）
2. **【可选进阶】人物突出卡片**：复制定格图层——上层抠出人物、加描边；下层原图轻微模糊。人物从背景里跳出来的定格卡片效果（漫剧高频用法，观感更精致）
3. **名字条**：新建文本「**角色名｜身份**」（例：角色名｜身份）——配贴纸/形状做底色标签条（**圆角矩形 + 细分割线**），放在人物旁边或底部
4. **动画与时长**：入场动画三选一（渐显 / 向右滑入 / 擦除），出场渐隐；标签**只停留 0.8–1.5 秒**；**只在第一次出场出现**，后续同人不再加
5. **卡点与音效**：标签出现时间与人物露出画面的时间**卡点同步**，配「**叮**」提示音效

## 二、动态人物的变通

人物在走动、无法定格时：文字用**跟踪功能**让名字跟着人物移动。但**默认方案仍是定格卡片**——更省事、更好看、更像漫剧。

## 三、分工链（分镜 ↔ 后期）

| 层 | 职责 |
|----|------|
| **storyboard-director（分镜层）** | 分镜表标注：该镜是谁的**首出场镜**（名条标注：`名条:角色名｜身份`）；首出场镜的「画面内容」里写明人物**入画卡点**（名条卡点对齐它） |
| **video-producer（后期层）** | 按本规范在收口阶段制作名条：定格→（可选抠像描边）→名字条→动画→卡点+叮音效；每角色仅一次，制作后在收口清单登记「名条:角色→集/镜」 |

## 五、自检

1. 全剧每个角色名条**恰好一次**（重复=返工）
2. 名条停留 0.8–1.5 秒、有入场动画、有「叮」音
3. 卡点=人物入画帧（不早不晚）
4. 名条文本与 §四表逐字一致
