# 出视频执行细则（工作流 · SOP · 翻车清单）

## 一、前置资产校验清单

1. 三视图：线条清晰、无歧义；服装边界、配饰轮廓明确；同角色不同套服装**五官完全统一**
2. 场景参考图：光影与角色美术风格对齐；**静态场景优先**（复杂动态场景降成功率）
3. 可选最优解：用三视图+定妆照训**角色 LoRA / IP-Adapter 权重**——角色稳定性的天花板，比单纯传参考图强

## 二、单镜隔离生成包

每镜独立打包，独立生成。**多镜单视频（2026-11-05 用户令）**：连贯戏允许多个分镜合并一条视频——一组时间码连续的镜打包成一个「多镜组生成包」，prompt.txt 内逐镜写「分镜N（时间码）」+ 入点与动作衔接上镜末态（写法见 storyboard-director `references/live-action-instruction-spec.md`）；其余结构不变，失败按时间码段归因，重生成只重跑崩坏时间段：

```
镜N 生成包/
├── prompt.txt        # 提示词（含一致性锁句，来自分镜块）
├── negatives.txt     # 负面词（按后端通道，见 backends.md）
├── ref/              # 角色参考卡（≤正面主+侧辅）+ 场景参考
└── params.txt        # 后端参数（试产锁参后的固定值）
```

❌ 禁止连续 N 镜一起丢给 AI 批量生成——批量连锁翻车，一崩全片废。

## 三、试产镜（2–3 个，锁参后再批量）

选代表性三镜：**特写、中景、带动作镜**各一。验证三件事：

1. 角色会不会变脸
2. 服装会不会跑
3. 镜头运动是否正常（漂移/闪烁/畸变）

测试通过 → 固化提示词结构、参考图组合、参数 → 批量跑剩余镜，**参数禁止再改**。测试不过 → 回分镜/素材层修，不硬跑。

## 四、素材入库规范

- 命名（2026-11-10 用户令）：`NNN_<分镜描述>_xx.mp4` 有序命名——NNN=三位数集内出片序号（001 起，按分镜顺序，导入剪辑软件后按剧情时间天然排序），`<分镜描述>`=一句话内容关键词（如 回廊拂柱），`xx`=镜号/版本标识；示例 `001_回廊拂柱_镜1.mp4`。一镜一文件，备选版本 `_v2` 后缀。禁止只用「第NNN集·镜N.mp4」无描述命名
- 元数据标注：成功/失败 + 失败原因四分类（**变脸 / 肢体崩 / 场景错 / 服装串**）
- 保留全部原始输出（含失败版）——失败版是重生成对照基线
- 崩坏镜头**只重生成该镜**（原节点重跑），不整段重做

## 五、后期统一收口（AI 生成只是素材）

1. 剪辑软件统一**调色 + 降噪**（AI 素材色彩/亮度天然有差）
2. 镜头衔接处**淡入淡出/切镜**掩盖 AI 帧间闪烁
3. 台词、音效、字幕、转场**全部后期叠加**，不依赖生成层
4. 崩坏镜单独重渲染兜底；特写崩坏可用 3D 数字人补镜（混合路线）

## 六、三条工具路线保底（按项目选）

| 路线 | 适用 | 保底策略 |
|------|------|---------|
| **A 图生视频**（即梦/可灵/Runway/Pika） | 轻量快跑 | 必上角色参考卡开参考模式；固定机位/慢推优先；动作极简；每镜 2 版挑优（30% 余量【经验·内部】，批4 核验） |
| **B 3D 管线**（Blender/UE/Unity 数字人） | 角色绝对不能错的项目 | 三视图直接绑模型、服装换资产；引擎内摆机位 K 动画——一致性最强，工作量最大 |
| **C 混合管线**（推荐） | 性价比最优 | 三视图→LoRA/权重+参考卡；分镜图做构图参考；AI 出表演片段；后期调色修复；崩坏特写 3D 数字人兜底 |

## 七、极简 SOP

1. 整理角色卡（正面主+侧背辅，一服一卡，固定角色 ID）
2. 虚拟导演输出全局风格规范（`../storyboard-director/references/director-brief.md` §五）
3. 分镜表逐镜打包（编号｜时长｜机位｜角色+服装｜场景｜动作｜光影｜负面词）
4. 试产 2–3 镜锁参
5. 单镜隔离批量生成，留 2 版备选，失败归因入库
6. 后期收口：调色对齐、配音字幕、崩坏镜单独重渲染

## 八、高频翻车清单（出片前逐条对照）

1. ❌ 三视图画风与场景图/分镜参考不一致（手绘 vs 写实混搭必崩）
2. ❌ 分镜时长超后端单段上限、动作过复杂 → 黑屏/扭曲
3. ❌ 同角色多服装镜未标注服装版本 → AI 随机混搭
4. ❌ 一次性塞太多参考图（正侧背+场景+分镜图）→ 参考信号冲突
5. ❌ 只定风格没有统一负面词 → 各镜崩坏标准不一
6. ❌ 依赖 AI 自己做镜头衔接、不拆镜不后期 → 角色跳变
7. ❌ 动态模糊/强运动镜头配人物特写 → 人脸漂移闪烁
