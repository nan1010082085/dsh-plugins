# style-3d-anime（精致 3D 日漫 CG · 风格段）

**风格定位**：人物设计走**日漫审美**（大眼睛、精致五官、动漫头身比例），渲染走**3D 立体 CG**（次表面散射皮肤、细腻材质、立体光影）——一句话：**日漫的脸，3D 的质感**。目标观感=顶尖 3D 二次元游戏 CG / 3D 动画电影级画面。与两个邻居划清界限：比 style-cg-refined 更「动漫」（脸和比例是日漫的），比 style-anime 更「立体」（不是 2D 平涂赛璐璐）。

## 何时使用

- 剧目锁定「精致 3D 日漫 CG」风格
- 用户提到：3D 日漫 / 3D 二次元 / 精致 3D 动漫 CG / 米哈游风 3D 质感（描述质感不引 IP 名）
- 出图/出视频需要取「风格段」且定位在日漫造型×3D 渲染之间
- 新中式国风 / 三渲二 / 国风角色设定图 → 取 `references/new-chinese-3d-anime-spec.md` 变体档案（国风服饰词库+风格锁模板+边界，2026-11-06 用户供风格口径）

## 流程

1. **确认风格锁**：一部剧 1 种风格全剧不换；锁定后全资产（基础形象设定卡/服装/表情/场景/视频）共用
2. **取风格段**：从 `references/style-profile.md` 取风格锁模板（中英）+ 高效组合，按 `shared/prompt-formula.md` §四五段式组装
3. **按后端方言调**：画质词/负面词/长度按 `shared/backends.md`
4. **脸与材质分开写**：脸部特征走日漫词（大眼睛/精致五官/动漫比例），材质走 3D 词（次表面散射/发丝分明/织物纹理）——两组词都要在，缺一边就漂向邻居风格
5. **翻车点自检**：对照 `references/style-profile.md` 翻车点表逐条过

## 硬闸与自检

- **禁写实真人词混入**：photorealistic / 真人皮肤质感 / 85mm / DSLR / 明星脸 不进本风格段——混入即漂向 style-cg-refined/photoreal，日漫脸被写实化，易出半写实不协调感（写实词混入→漂向写实/半写实有实证【社区实证·Reddit PSA + Civitai】，「恐怖谷」断言已降级【社区经验】）
- **禁 2D 平涂词混入**：赛璐璐 / 粗描边 / 色块平涂 / 扁平 不进本风格段——混入即漂向 style-anime，3D 质感被压平【推测】（机理自洽、无直接 A/B）
- **禁翻车词**：soft-glow / painterly 修饰词禁入（明文翻车词，与 cel 质感对冲【社区经验·Anifusion】）；halftone（西漫）与 screentone（日漫）禁混写、commit 其一【社区实证·artpromptsgenerator】
- **脸与质感双锚都在**：日漫造型词（大眼睛/动漫比例）+ 3D 渲染词（立体建模/次表面散射）必须同时在场，缺一必漂
- **禁知名 IP/角色名**：风格描述≠复制角色，禁引具体游戏/动画 IP 名与角色名
- 画质词分平台（`shared/backends.md`）；广告闸/花钱门照常（`shared/hard-gates.md`）
- 出图前置调研（`shared/pre-gen-research.md`），新结论沉淀回 `references/style-profile.md`

## 产出与格式

- **产出**：风格段文本（可直接嵌入五段式组装 / 出视频指令【氛围与画质】段）
- **沉淀**：调研/实战发现回写 `references/style-profile.md` 翻车点表，标日期与来源
