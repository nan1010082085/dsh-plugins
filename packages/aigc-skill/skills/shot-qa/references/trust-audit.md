# 分镜可信度审计（trust-audit，2026-10-29 用户令）

> 「分镜内容到底有多少可信」的量化答案。逐镜六维打分，产出 A/B/C 评级与不可信镜清单。
> 机检器：`tools/trust_audit.py <分镜文件或目录>`；人检项由导演判读并记录理由。
> 新写/重写分镜必须达到 A 才准进生成包；存量分镜按本审计出清单、C 级强制重写。
>
> **阈值来源注记（2026-10-31 批4 核验·被校正条目留注记）**：T1 35%/25%、T3 65%/80%、T5「≥3 处判 C」等**全部阈值数值=【经验·内部启发式·无行业依据】**——查无任何外部标准；行业与学术均不用加权百分比阈值。**数值一律保留**（`tools/trust_audit.py` 依赖，改数=改工具行为）；六维框架与 A/B/C 评级规则=2026-10-29 用户令（U 级），不在校正范围。
> **行业对照**：AI 视频 QC 的通行形态是「逐项 PASS/FAIL + 时间码定位 + 严重度分级（Critical/Warning/Info）+ 严重度计数升级（Critical 计数→FAIL）」，不存在加权总分/百分比阈值标准【行业：framesense.io，2026-10 访问】。本表阈值只作内部启发式用，对外/跨团队汇报时禁写成行业标准。

## 六维评级

| # | 维度 | 机检/人检 | A（可信）标准 | 判 C 条件 |
|---|------|----------|--------------|----------|
| T1 | **叙事占比** | 机检 | 【画面内容】叙事字数 ≥ 全段 35%，动词链逐拍（阈值【经验·内部】） | 叙事 < 25%（描述空心）（阈值【经验·内部】） |
| T2 | **自足性** | 机检 | 无任何跨镜复述依赖，本镜画面自己讲完 | 命中禁词：同镜X完整描述/复述锚点/以本描述为准/完整状态照写 |
| T3 | **模板复读** | 机检 | 与同集他镜正文相似度 < 65%（光影允许风格一致，禁整段复制）（阈值【经验·内部】） | 相似度 ≥ 80% 的整段复制（阈值【经验·内部】） |
| T4 | **运动真实** | 机检+人检 | 位移镜三要素（动线/步速/谁动）齐；无双动叠加；动作有支点 | 位移镜无动线，或镜头推拉与行进同向叠加 |
| T5 | **生产纯净** | 机检 | 正文零 @引用头/〔〕/编译器指令/表情资产字眼 | ≥3 处生产元注释污染（计数阈值【经验·内部】） |
| T6 | **五要素覆盖** | 人检 | 演什么/怎么动/怎么拍/什么光/什么声 各有落点且属于本镜 | 缺 ≥2 要素，或要素内容是从他镜抄的 |

## 评级

- **A（可信）**：六维全过 → 可进生成包；
- **B（待修）**：≤2 维不过 → 修完复审才准出片；
- **C（不可信）**：≥3 维不过，或 T2/T4 单维判 C → **强制重写**，禁止带病出片。

## 审计产出格式（写进交付/Notion）

```
可信度审计：A｜T1 叙事 42% 过｜T2 自足 过｜T3 复读 51% 过｜T4 动线齐 过｜T5 纯净 过｜T6 五要素 过
```
C 级必须附：命中禁词/缺失要素/复读段出处 + 重写要点。
