# novel-to-drama（小说改编 · 分集编剧）

把小说（番茄小说等网文链接，或本地正文）改编成分集剧本条目。**根原则：由小说出发进行改编**——
小说是唯一事实源，改编 = 取尽 + 补完 + 扩写成画面，不删不缩水、不脱离原著自创。

参考文件（规则引用，不复述全文）：

- `shared/split-methodology.md` —— 拆分与改编方法论（换算锚/故事单元/连贯改编技法/每集结构模板），分集规则的唯一真相源
- `shared/output-formats.md` —— LOCKED 剧本条目契约，字段名逐字引用（`集数` / `时长秒` / `场景节拍[]` / `人物[]` / `本集看点` / `结尾钩子`）
- `shared/hard-gates.md` / `shared/lessons.md` —— 硬闸总纲与历史翻车点
- `shared/script-standard.md` —— **剧本内核参考**（内核五条 + 七段式载体建议），故事灵魂的参照系——**吸收 DNA 不抄格式**
- `shared/script-craft.md` —— **剧本文风与叙事技法**（好坏对照/技法七条/三稿制/可读性验收），剧本质量的唯一真相源
- `references/adaptation-workflow.md` —— 改编操作细则（标转折点→分组场景→逐集撰写→连贯检查→时长自然成型；开头黄金秒链；钩子设计；改编取舍账本；两核心验收）
- `tools/fanqie_ocr.py` —— 番茄正文确定性抽取器（字体反爬：本地渲染 + macOS Vision OCR）

## 何时使用

- 用户丢来小说链接（番茄小说等）或本地小说文本，要求改编漫剧/短剧、出分集剧本。
- 用户要求做分集方案、拆集、定每集时长与看点钩子。
- 用户要求盘点小说人物、伏笔、名场面，或评估一部小说的改编密度。
- 下游 `storyboard-director`（剧本条目 → 分镜块）的上游前置；`idea-to-drama`（原创剧本）走同一分集契约。

## 流程

### 第 1 步：抽正文（OCR / 直取二选一）

先判反爬形态，二选一，不混用：

- **有字体反爬（番茄等字形混淆站点）**：走 `tools/fanqie_ocr.py` 三步——
  1. **build_ocr**：备好 macOS Vision OCR 可执行 `ocr-vision`（`OCR_VISION` 环境变量指定路径，或放脚本同目录）；
  2. **catalog + raw 导出**：`python3 -I tools/fanqie_ocr.py <reader_url> --out DIR --catalog-only` 拿 `catalog.json` / `book-meta.json`；curl/urllib 直连会被降级为 200 字试读，章节正文必须用浏览器页上下文 fetch 导出到 `DIR/raw/batch-*.json`；
  3. **from-raw 重建**：`python3 -I tools/fanqie_ocr.py --from-raw --out DIR`（依赖 `uv run --with fonttools --with brotli --with pillow`）——本地渲染 subset 字体 + OCR 重建 `DIR/novel/ch*.txt`。
- **无反爬**：直接取文本（本地文件/可复制正文），不做 OCR，正文落 `novel/ch*.txt` 同构即可。

产出：全书正文按章编号 + 目录（`catalog.json`）。**抽文只求忠实还原，不改写不摘要。**

### 第 2 步：拆解（逐卷精读）

按 `shared/split-methodology.md` 第五节拆解项逐卷过一遍：

- **人物盘点三级**：主角 / 配角 / 路人，记录说话方式与性格特征（供剧本「人物靠对话」用）；
- **人物弧线与关系演进**：谁在哪一段变强/反转/决裂；
- **伏笔**：埋点与回收点成对登记，改编不得丢；
- **名场面**：高光时刻单独标出（分集时独立成集并加爆点）；
- **爽点 / 冲突密度分布**：标出密度高低段，砍水戏、保密度。

### 第 3 步：分集方案（先故事单元，后字数校对）

改编总纲（2026-10-31 入库）【工具商社区·剧现《小说改编短剧工作流》 https://pages.puzle.cn/workflows/novel-adaptation/ 】：「改编不是把小说删短，也不是逐章翻译成场景。它是在新的作品形态、受众、集数和时长约束下，重新建立一条能兑现原作核心价值的因果链。」

- **一集 = 一个微事件**：目标/冲突 + 起承转合 + 结尾钩子；单集 1–3 个场景。**每集六件**：目标 / 阻碍 / 关键选择 / 代价 / 关系信息资源变化 / 尾钩——**尾钩必须来自本集选择的后果**，不是临时加的无关危机【工具商社区·剧现】。
- **拆分刀口跟情节点走**：先列全剧转折点，再围绕转折切分集数（发现线索 → 遭遇阻碍 → 突破/反转）。
- **禁止「一章 = 一集」机械映射**：一章可能藏着三个可用转折，也可能一个都没有——一集可跨多章取材，一章名场面密度高也可拆多集；字数换算（1 分钟 ≈ 台词 200–240 字，配音口径；动作/说明另计）只做初算锚，先按故事单元拆、再用字数校节奏，顺序不能反（2026-10-31 校准：原 200–400，400 上限无行业出处——【社区/行业经验·配音口径】）。禁令同口径出处：【工具商社区·剧现 + DramaSo https://drama.so/zh/blog/short-drama-script-structure （「一章≠一集，先列转折再分集」）】。
- **连贯标题必须同集**；**名场面独立成集**并加爆点；每集必须装满戏剧容量（冲突/钩子），装不满与相邻单元合并。
- **时长自动成型**：每集 `时长秒` 由节拍与分镜自然得出，正片 60–120 秒区间，不硬凑不牵强；30–60 秒只用于引流切片，不作正片集（2026-10-31 校准：原 30–120，30 秒档低于主流口径——【社区共识·DramaSo/数艺社】，平台规则明文未见）。
- 体量参考（非硬约束）【社区·DramaSo 转引 TheWrap 行业包装口径】：全季约 60–100 集、约 90 秒/集，付费墙通常落在第 10 集左右（前 8–10 集免费=付费转化试镜）；社区实操文口径 20–80 集、单集 1–2 分钟作旁证。

### 第 4 步：分集剧本（两核心同时成立）

逐集写剧本条目（字段契约见 `shared/output-formats.md` 第 1 节），验收看两核心（细则见 `references/adaptation-workflow.md`）：

- **灵活叙事**：冲突密度高、砍水戏、每场戏直接可拆镜头，产出即进分镜不返工；
- **剧本理解**：原著人物 / 伏笔 / 名场面不走样，保留原作梗与名台词（名台词 ≤20 字照引——≤20 字系**【自定 house rule·无行业出处】**，2026-10-31 校准标注；照引短句不构成版权豁免，风险见硬闸）。

硬性写法：**黄金秒链**——起手 3 秒钩子（直接冲突/强悬念/极致反差三型）、10 秒内立矛盾、30 秒内首爆点、每 20–30 秒一个情绪节点（原「开头 5 秒抓人」并入链口径，2026-10-31 校准）【社区·数艺社/DramaSo＋官方媒体·文汇报佐证完播口径】；慢热开头重构为动作/对话直入；结尾必留钩子（原文结尾平缓就调顺序、把后面的冲突提前），且第 N 集悬念 = 第 N+1 集钩子；人物靠对话和选择体现性格，禁旁白交代；叙述→视听（心理描写转动作/表情/潜台词）。

**三稿制（2026-10-27 用户令：剧本必须可读，结构合格≠剧本合格）**：初稿（结构）→ 精修稿（按 `shared/script-craft.md` 文笔技法逐场精修：五感开场/动作链/对白两层/节奏呼吸/删废话）→ 定稿（**内核五问+人读验收**（`shared/script-standard.md` §四）：内核在场/放电影/情绪曲线/反差成立/幽默温情/设定够用/结尾仪式，逐集签字）。**改编同样要有内核一句话**（这集真正讲什么）——原著主题的当集落点；每集载体按 `shared/script-standard.md` 七段式（故事内容=叙事散文体为本体）。一稿交付=违规，提纲式输出=废稿。

### 第 5 步：交付

1. **分集方案表**：集数 / 覆盖章节 / 微事件一句话 / 预估看点。
2. **剧本条目数组**：字段名逐字用契约原名，每集一条，全局连续编号。
3. **改编对照 / 取舍账本**（2026-10-31 升级）【工具商社区·剧现】：每集标注取材章节范围与保留的名台词/名场面；每个保留/删除/合并记「元素/处理/理由/影响/替代」五列，合并角色须说明功能转移——供下游核对不走样。
4. 交下游 `storyboard-director` 拆分镜；本 skill 不触发任何生成。

## 硬闸与自检

- **禁一章一集**：机械按章节映射 = 分集失败（`shared/split-methodology.md` 第二节）。
- **时长正片 60–120 秒自动**：不为凑时长注水、不为压时长砍戏；`时长秒` 超界回第 3 步重排（30–60 秒仅引流切片；2026-10-31 校准：原 30–120）。
- **看点/钩子句号收尾**：`本集看点`、`结尾钩子` 各一句话、句号收尾；钩子不在场 = 该集不定稿。
- **连贯检查过才定稿**：每集开头承接上集 + 结尾钩子在场 + 主线贯穿（`shared/split-methodology.md` 第四节）。
- **零压缩铁律**：小说原文与名台词逐字引用不改写，名台词 ≤20 字照引（`shared/hard-gates.md` 第 3 节）——≤20 字系**【自定 house rule·无行业出处】**（2026-10-31 校准标注）。
- **照引风险注意（2026-10-31 入库，风险提示非禁令）**【官方·检察日报/最高检（著作权法第 24 条三步检验：法定情形+不冲突正常使用+不损害合法权益，司法从严、封闭列举）+ 专业媒体·MovieMaker Cinema Law】：短句非必然免责——承担核心表达的短语可受保护（如 "Rosebud"），使用语境影响认定；转换性不足的照搬难构成合理使用；**能拿授权就拿授权**。细则见 `references/adaptation-workflow.md` §四。
- **人物不走样**：`人物[]` 逐人可挂资产（对齐 assets.json 的 `characters.name`），露脸角色全挂；性格靠对话不用旁白。
- **品牌三层都禁**：剧本的台词/旁白/字幕文案不得出现真实品牌（`shared/hard-gates.md` 第 6 节，交付前过 `tools/brand_scan.py`）。
- **不烧积分**：本 skill 只产剧本，不执行生成；出图/出片必经花钱门与 Notion 审核（`shared/hard-gates.md` 第 1、2 节）。
- 违禁废话词、翻车点对照 `shared/hard-gates.md` / `shared/lessons.md` 通读一遍再交付。

## 产出与格式

- **产出**：剧本条目数组，字段名逐字引用 `shared/output-formats.md` 第 1 节 LOCKED 契约：
  `{集数, 时长秒, 场景节拍[], 人物[], 本集看点, 结尾钩子}`。
- **场景节拍[]**：元素为 `{目标/冲突, 起承转合, 钩子}`（字段名含斜杠，照写）；哪怕很短，起承转合也要齐。
- **时长秒**：正片 60–120，自动——由节拍与分镜自然成型，不硬凑（30–60 秒仅引流切片）。
- **人物[]**：本集出场人物名，与 assets.json 的 `characters.name` 对齐，逐人可挂资产。
- **本集看点 / 结尾钩子**：各一句话，句号收尾。
- 约束：单集 1–3 个场景、一集一个微事件、全局集数连续。
- 下游衔接：剧本条目交 `storyboard-director` 产分镜块（`shared/output-formats.md` 第 2 节）；字段名冲突时以契约为准，改文案不改契约。
