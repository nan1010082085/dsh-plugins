# 改编操作细则（adaptation-workflow）

> `novel-to-drama` 的操作层细节。规则本体在 `shared/split-methodology.md`（7 步操作序：拆解 → 标转折点 → 分组场景 → 排集 → 逐集撰写 → 连贯检查 → 时长自然成型），本文件不复述，只写**怎么落地与怎么验收**。
> 根原则重申：由小说出发进行改编——取尽 + 补完 + 扩写成画面，不删不缩水、不脱离原著自创。
> 改编总纲（2026-10-31 入库）【工具商社区·剧现《小说改编短剧工作流》 https://pages.puzle.cn/workflows/novel-adaptation/ 】：「改编不是把小说删短，也不是逐章翻译成场景。它是在新的作品形态、受众、集数和时长约束下，重新建立一条能兑现原作核心价值的因果链。」

## 一、拆解到分集的落地序（对应 7 步中的 2–7 步）

1. **标转折点**：逐章按「发现线索 → 遭遇阻碍 → 突破/反转」在原文标情节点；一章标不出转折点 = 水章候选，改编时压缩或并入相邻单元。一章可能藏着三个可用转折，也可能一个都没有——**先列转折，再围绕转折切分集数**【工具商社区·剧现 + DramaSo】。
2. **分组场景**：场景按转折点/情绪高潮归入微事件单元，每单元 1–3 场景；一章铺开 5 场景就按刀口分两组，不硬塞一集。
3. **排集**：微事件落位成集——跨章取材、一章拆多集都按需；**连贯标题必须同集**，**名场面独立成集并加爆点**；用换算锚（1 分钟 ≈ 台词 200–240 字，配音口径；动作/说明另计）校节奏，只校不切（2026-10-31 校准：原 200–400，400 上限无行业出处——【社区/行业经验·配音口径收敛】）。
4. **逐集撰写**：按每集结构模板（`shared/split-methodology.md` 第四节）写剧本条目，字段契约见 `shared/output-formats.md` 第 1 节。**每集六件**【工具商社区·剧现】：目标 / 阻碍 / 关键选择 / 代价 / 关系信息资源变化 / 尾钩——**尾钩必须来自本集选择的后果**，不是临时加的无关危机。
5. **连贯检查**：开头承接上集 + 结尾钩子在场 + 主线贯穿，过了才定稿；不过回第 4 步改，不带病交付。
6. **时长自然成型**：由节拍密度得 `时长秒`（正片 60–120 自动；30–60 秒仅引流切片）——超出区间说明单元拆得不对，回第 3 步重排单元，禁止注水或砍戏硬压（2026-10-31 校准：原 30–120，30 秒档低于主流口径——【社区共识·DramaSo/数艺社】）。
7. **字数只做初算锚**：先按故事单元拆、再用字数校对节奏，顺序不能反（`shared/split-methodology.md` 第一节）。

## 二、开头黄金秒链（原「开头 5 秒抓人」并入链口径，2026-10-31 校准）

**黄金秒链**【社区·数艺社 https://www.163.com/dy/article/L30RCS1005340TH8.html + DramaSo https://drama.so/zh/blog/short-drama-script-structure + Filmustage 转引；完播口径佐证【官方媒体·文汇报/光明网 https://e.gmw.cn/2026-06/23/content_38843027.htm 】】：

`0–3 秒黄金钩子（三型：直接冲突 / 强悬念 / 极致反差）` → `10 秒内交代核心矛盾+人物关系+主角目标` → `30 秒内第一次反转/爽点` → `每 20–30 秒一个情绪节点` → `结尾 5–10 秒强钩子（= 下集钩子）`。

- 慢热开头（大段世界观/身世/景物描写起手）必须**重构成动作或对话直入**：起手 3 秒给钩子，前 5 秒给到悬念或冲突，10 秒内立矛盾。
- 手法：把第一章的第一个冲突/异常事件提到开场；设定与背景拆散，融进冲突中的对话与动作里事后补。
- 每集同理：集首第一个节拍必须是动作/对话/异常，不是叙述铺垫——**开场铺垫（环境/心理描写）超 10 秒 = 直接划走**（低完播三大坑之首）【社区·数艺社】。
- 验收：读集首前两句——没有冲突或悬念在场 = 打回重写开头；对照黄金秒链查 3s/10s/30s 三档落点。

## 三、钩子设计（结尾必留 Cliffhanger）

- 每集结尾挂钩子；**原文结尾平缓就调顺序，把后面的冲突提前**——钩子可以与下集首个节拍同源；**第 N 集悬念 = 第 N+1 集钩子**【社区·DramaSo】。
- 钩子类型参考：新威胁现身 / 关键信息只说一半 / 选择摆在面前未作答 / 反转打脸前一刻；高转化收尾三类：悬念钩 / 危机钩 / 反转钩【社区·数艺社】。
- **悬念五型收尾**【社区·DramaSo】：揭示式 / 打断式 / 抉择式 / 反转式 / 威胁式——定格在下一集开场要回答的问题上。
- 钩子与看点分家：`本集看点` 说本集爽在哪，`结尾钩子` 说为什么必须看下一集；各一句话、句号收尾。
- 验收：把结尾钩子遮住能自然猜到下集走向 = 钩子不合格，回炉。
- 单集节奏骨架（60 秒七节拍/扩展规则/升级测试三列：谁握权力、观众知道什么、什么处于危险中，每节拍至少挪动一列）见 `../idea-to-drama/references/idea-workflow.md` §六 同源表【社区·DramaSo】；**低完播三坑**负面清单同查：铺垫 >10 秒 / 结尾无钩子 / 持续虐主角无反击缓冲【社区·数艺社】。

## 四、人物靠对话和选择，不用旁白

- 性格、立场、能力全部通过**说话方式**（口癖/敬语/长短句/称呼）与**关键选择**体现；禁止旁白「他是个冷漠的人」一类直接交代。
- 叙述 → 视听：心理/背景描写转成动作、表情、潜台词、环境细节（「他很害怕」→「手心出汗、后退一步、声音颤抖」）。**叙述转场景三转换**（2026-10-31 入库）【工具商社区·剧现 + DramaSo】：内心活动 → 可观察目标；背景说明 → 当前阻碍；情绪判断 → 关系变化或代价——**竖屏观众听不见心理活动**。对照示例（剧现）：弱转换「她想起童年，因此决定留下」→ 可表演转换「她准备离开时发现弟弟抵押了母亲留下的店，若今晚不签担保，店会被拍卖；留下意味着替曾背叛她的家人承担债务」。
- **台词铁律**（2026-10-31 入库）【社区·Filmustage 竖屏编剧指南（转引 DramaSo）+ 数艺社】：台词尽量短、碎、锋利，一镜一句，杜绝大段长篇对话；每句必须推进冲突、或在压力下揭示人物——不允许闲聊和「摆桌子」的铺垫台词。密度按台词 200–240 字/分钟估算（配音口径，§一-3）。
- 人物盘点三级（主角/配角/路人）在拆解阶段记录每人说话特征，写对话时逐人对齐，防止串味。
- 保留原作梗与名台词：名台词 ≤20 字**照引原文**，不改写不润色——≤20 字系**【自定 house rule·无行业出处】**（2026-10-31 校准标注：全量检索无任何行业/书籍给出台词字数上限；社区旁证仅「短碎锋利/一镜一句」定性主张与示例句约 10–25 字）；梗保留不了要说明取舍，不许静默丢弃。
- **照引风险注意（2026-10-31 入库，风险提示非禁令）**：短句非必然免责——美国口径短语通常不达版权「独创性」门槛，但**在作品中承担核心表达（如 "Rosebud"）可受保护**，使用语境（顺带提及 vs 全片论点）影响认定（Faulkner 诉 Sony 案《午夜巴黎》转述一句被驳回，理由之一是引用占比极小）；中国口径著作权法第 24 条**三步检验**（法定情形+不冲突正常使用+不损害合法权益）司法从严、封闭列举，转换性不足的照搬难构成合理使用；律师建议**能拿授权就拿授权**【官方·检察日报/最高检 https://www.spp.gov.cn/spp/llyj/202505/t20250513_695472.shtml + 专业媒体·MovieMaker Cinema Law https://www.moviemaker.com/what-to-know-using-peoples-quotes-film/ 】。

## 五、剧本两核心的具体验收标准

### 灵活叙事（节奏紧凑、镜头精炼、快速成片）

- **冲突密度高**：每集至少 1 个正面冲突 + 1 个钩子；单集节拍里纯过渡/纯说明的节拍占比不超过三分之一。
- **砍水戏**：重复情绪、无目标闲聊、纯赶路/纯回忆的场景砍掉或并入有冲突的场景；砍了要在改编对照里记一笔。
- **每场戏直接可拆镜头**：每场戏写成可分镜的视听事件（谁在哪做什么说什么），不含「一段时间过去了」一类不可拍叙述；产出即进 `storyboard-director` 不返工。

### 剧本理解（深度理解、读懂每一份剧本）

- **人物不走样**：动机链、能力边界、关系演进与原著一致；改编对照里标注每集人物弧线取材章节。
- **伏笔不走样**：埋点与回收点成对保留，位置可挪但不可丢；挪了标注新位置。
- **名场面不走样**：名场面独立成集并加爆点，但核心动作/台词/反转顺序不改；名台词 ≤20 字照引**【自定 house rule·无行业出处】**。
- **改编取舍账本**（2026-10-31 入库）【工具商社区·剧现】：每个保留/删除/合并记「元素/处理/理由/影响/替代」五列（合并角色须说明功能转移）；三类资产判定——**故事资产**（删掉就失去辨识度，不可删）/ **结构负担**（适合阅读难转行动，可删）/ **改编机会**（略写但可视觉化冲突化，应扩写）。
- **每集一个价值翻转（McKee 场检验）**【书籍·Robert McKee《故事》，官网引文 https://mckeestory.com/do-your-scenes-turn/ 】：场首与场尾的价值正负电荷必须变化；只有 exposition 的场应删掉并把信息织入别处（定义/用法见 `shared/script-craft.md` §二-8）。
- 验收方式：逐集过「改编对照/取舍账本」（取材章节 + 保留的名台词/名场面 + 改动取舍五列），对不上的回第 4 步补。

## 六、交付前快检（逐集）

- [ ] 集首 3 秒钩子在场、10 秒立矛盾、30 秒首爆点（黄金秒链，第二节）
- [ ] 结尾钩子在场、句号收尾、遮住不能猜到下集；第 N 集悬念 = 第 N+1 集钩子（第三节）
- [ ] 无低完播三坑：铺垫 >10 秒 / 结尾无钩子 / 持续虐主角无反击缓冲（第三节点名负面清单）
- [ ] 性格全在对话与选择里，无旁白交代；台词短碎锋利、无闲聊摆桌子（第四节）
- [ ] 名台词 ≤20 字照引【自定 house rule·无行业出处】、伏笔/名场面在改编对照里有落点（第五节）
- [ ] 每集至少一个价值翻转（McKee 场检验，第五节）
- [ ] 每集六件齐（目标/阻碍/关键选择/代价/变化/尾钩），尾钩出自本集选择后果（第一节）
- [ ] `时长秒` 正片 60–120 且自然成型（30–60 仅引流切片；第一节）
- [ ] 单集 1–3 场景、一集一个微事件、集数连续（`shared/output-formats.md` 第 1 节约束）
