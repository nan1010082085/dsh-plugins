# style-cyberpunk（赛博朋克 · 风格段）

剧目风格锁为「赛博朋克」时的风格段出口。风格段 = 风格锁句 + 高效组合词组 + 后端画质/负面词尾巴；霓虹是本风格专属武器，不进任何其他风格。

## 何时使用

- 剧目风格锁为「赛博朋克」（含霓虹城市全景/暗黑赛博/复古赛博/轻科幻子类）时，取本风格段
- 用户问：赛博朋克 / cyberpunk / 霓虹都市风提示词怎么写
- 新剧立项定风格、或人物三视图/场景空镜/分镜成片需要统一风格段

## 流程

1. **确认风格锁**：一部剧只锁 1 种风格，全剧不换（与 `shared/director-styles.md` 全剧基调对齐）；先定子类（霓虹城市全景/暗黑赛博/复古赛博/轻科幻）
2. **取风格段**：从 `references/style-profile.md` 取「风格锁模板」（中/英各一版）+「高效组合」词组，组装风格段
3. **按后端调方言**：画质词/负面词按 `shared/backends.md` 与 style-profile「负面词与画质词策略」分流；霓虹招牌文字按后端写法（Flux/即梦引号写明内容）
4. **总装**：风格段嵌入五段式组装（`shared/prompt-formula.md` §四），与人物锚点段、场景锚点段拼接；光影四件套（光源位置+类型+色温/时段）必写进场景段
5. **翻车点自检**：对照 style-profile「翻车点与对策」逐条过，重点查光源布局与人脸受光

## 硬闸与自检

- **风格污染警告（本风格头号红线）**：neon/霓虹/赛博光源只进本风格段——写皮克斯/田园/日漫清新场景时误加霓虹即毁图（研究 §4-4）；一剧一风格不混搭
- **禁知名角色名/受保护角色**：风格描述≠复制角色，禁写银翼杀手等影片/角色专有名
- **画质词按后端分流**：禁统一挂 8k/RAW/masterpiece——Flux/GPT/即梦/MJ 上是噪声【社区实证·Promgrammer】，换具体材质词（湿漉沥青反光、铬金属、全息贴膜）（研究 §3）
- **人脸受光硬条件**：人物特写/近景必写「人脸清晰受光、面部轮廓光」，防霓虹光污染盖脸
- **出图前置调研**：新疑问先走 `shared/pre-gen-research.md` 四步，结论回写 style-profile.md

## 产出与格式

- **产出 = 风格段文本**（中文版 + 英文版，可直接嵌入五段式组装的风格位）
- 风格段固定三件：风格锁句（整段复制）+ 高效组合词组（按需摘取）+ 后端画质/负面词尾巴
- **沉淀规则**：调研/实战新发现回写 `references/style-profile.md`，标注来源；未查证处标【推测】
