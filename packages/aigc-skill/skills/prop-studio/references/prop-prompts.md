# 道具生图指令骨架（五段式道具版 · 2026-10-28 二版）

> 提示词结构：**主体 + 剧本描述 + 使用痕迹 + 材质光影 + 画风约束 + 漫剧分层要求 + 排除约束（正向排除句）**。核心纪律：造型锚点写死、比例参考入图、透明底、一图一物一状态。〔…〕为占位符。
> 注记：原「+负面词」已被火山官方 API 校正 2026-10——Seedream/即梦 API 无 negative_prompt 参数，排除意图写成 prompt 正向句；SD 系后端有负面框时才把同批词放负面框（`shared/backends.md` 方言）。

## 1. 通用提示词模板（关键道具 · t2i · 主视图为主）

```
漫剧道具设定图，〔道具名〕。〔剧本描述：形状/尺寸/材质/花纹/颜色——与拆解表逐字对应〕；
〔使用痕迹：划痕/磨损/掉漆/污渍/修补——只写剧本逻辑支持的痕迹〕；
〔材质光影：如「哑光旧银、氧化黑渍、柔和左上暖光源」——与全剧光影规则一致〕；
〔画风约束：与本漫剧人物画风统一、干净轮廓线/厚涂写实等〕；
漫剧分层要求：透明背景，单独物件，无多余背景，〔比例参考：半个手掌大/与成年男性手掌对比〕；
清晰细节，适合特写镜头。白色干净背景（交付透明底 PNG）。
画面布局：单张主视图居中完整展示（**道具不需三视图**，2026-11-06 用户令）；复杂道具按需加一处侧面/四分之三透视辅助图+材质纹理特写分块（材质/倒角标注区）；结构复杂道具按需另加部件拆解小图（结构分层/爆炸示意）。
排除约束（正向排除句）：画面中无任何人物、无复杂背景、无阴影杂乱、无过度渲染、无崭新光亮感、不变形、不模糊、无多余装饰、无文字。
```

> 注记（排除约束）：原「负面提示词：复杂背景，人物，阴影杂乱，过度渲染，崭新光亮，变形，模糊，多余装饰，文字」已被火山官方 API 校正 2026-10（无 negative_prompt 参数）——即梦/Seedream 走正向排除句；SD 系负面框后端可将同批词放负面框。
> 材质词效注记（社区实证：Reddit r/StableDiffusion / Promgrammer / Civitai）：「次表面散射/SSS」类材质词在 SD 系写实侧有效（含轻微推近+柔和背光副作用）、与 3D 渲染语料强关联；Flux 词效有限需 SSS LoRA 补；**Seedream/即梦侧无任何 A/B 实证（查不到）**——即梦出图材质以具象中文描述（哑光旧银/氧化黑渍）为准，SSS 类术语属跨模型借用勿当保证；intricate details/super detail 类细节词过用产生 busy 的「AI 感」纹理，材质词克制使用。

## 3. 状态变体（i2i 挂主图 · 唯一合法出法）

```
〔风格句〕。同一道具（造型、花纹、材质与参考图完全一致），状态变更为〔状态名〕：
〔状态差异逐项写死：如「满水→半杯」「封面合拢→翻到第3页页角折起」〕。
透明背景（交付透明底 PNG），比例参考与主图一致。
构图锁：与参考图同机位同构图，只改状态要素，禁止改造型花纹，禁止变形，不要文字，高清4K。
```

改动程度控制（官方：火山方舟《图片生成 API》2026-10-14）：无重绘幅度参数，靠「保持 X 不变，将 Y 改为 Z」指令句——本模板「只改状态要素，禁止改造型花纹」即此写法的道具版（官方示例句式：「保持模特姿势和液态服装的流动形状不变。将服装材质从银色金属改为完全透明的清水」）。

## 4. AI 翻车三解法（实操纪律）

1. **文字/刻字乱码**：**刻字/标签/编号不让 AI 直出——先出无字版，后期 PS/Procreate 手动加字**，保证剧本文字准确。小字真实口径（社区实测：smzdm 聚合/知乎）：「AI 小字必乱码」是概率性硬规律——4 个大字可对、20 个小字几乎必错，单块 ≤10 字可试直出且 prompt 写死「文字清晰可读、笔画完整、无乱码」仅降概率不根治；小字号/密集排版/中英混排错误率陡升，成片级文字默认后期叠字（原绝对表述已按社区实测校正 2026-10）
2. **每次生成长得不一样**：**提示词固定一套（锚点短语+画风词一字不差）+ size 固定；把第一张合格图存为参考图，后续走 i2i 挂主图 + 指令式编辑句**（「保持造型、花纹、材质不变，将〔状态A〕改为〔状态B〕」），重生成必抽卡
   > 注记：原「固定种子」「i2i 重绘幅度 0.3–0.4」已被火山官方 API 校正 2026-10——Seedream/即梦官方图片生成 API 无 seed、无 strength/denoise 参数；「锁参数」=锁 prompt+参考图+size，改动程度靠「保持 X 不变，将 Y 改为 Z」指令句（见 §3/§9）
3. **光影脱节**：i2i 时同时挂一张本集人物/场景图作风格参考（光比、色调向它对齐）

## 5. 特写版 + 远景版（两套交付）

- **特写版**：细节拉满（纹理/刻痕/材质）——特写镜头用
- **远景版**：简化细节（省材质纹理层）——普通镜头用，省渲染不糊脸

## 6. 手绘方案（备用）

草图先放进场景缩略小图核对比例造型→细化→分层绘制（固有色层/阴影层/高光层分开），方便后期改色调适配场景。

## 6.5 原画三原则（设计层纪律，2026-10-28 调研提炼）

1. **轮廓优先**：先锁清晰可辨的剪影（远景也能认出是什么道具）——远景版按剪影+简化细节出
2. **功能先于装饰**：先锁功能性结构（能拿能用能动的部位），装饰细节后加——防过早堆花纹毁可读性
3. **蓝图属性**：主视图=复用蓝图——造型锚点写死，跨镜重绘时照卡复刻（道具不需三视图，2026-11-06 用户令；辅助视图按需不作要求）

## 7. 防穿帮五条（每图自查）

1. 造型锚点短语（形状/花纹/材质/颜色/尺寸）在图且与资产注册一字不差
2. 比例参考在图（**统一用主角手掌比**）
3. 白底/透明底、一图一物一状态、无文字标注（文字后期加）
4. 光影与全剧光影规则/人物设定卡匹配（柔和影棚光为默认）
5. 无品牌无商标无包装（过 `tools/brand_scan.py`）

## 9. 即梦/Seedream 调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）

调用生成前逐条过（风格段/排除段方言仍按 `shared/backends.md`）：

- **prompt 中文 ≤300 字（英文 ≤600 词）**：官方明示「字数过多信息容易分散，模型可能因此忽略细节……造成图片缺失部分元素」——超长砍形容词保要素
- **`watermark=false` 必设**：默认 true 会在右下角打「AI 生成」水印，出片素材一律显式关闭
- **返回 URL 24h 失效**：`response_format=url` 的链接生成后立即下载转存入库，禁止只存 URL
- **无 seed 参数（官方否定结论）**：不承诺复现；「锁参数」=锁 prompt+参考图+size，重生成必抽卡
- **无 negative_prompt 参数（官方否定结论）**：排除意图写成 prompt 正向排除句
- **无 strength/重绘幅度参数**：i2i 改动程度用「保持 X 不变，将 Y 改为 Z」指令句控制
- **多参考图按「图1/图2」序号引用输入顺序**（官方示例：「将图1的服装换为图2的服装」）：状态变体挂主图（图1）+ 场景/人物图作风格参考（图2）时点名「图1/图2」；Seedream 4.0/4.5/5.0 lite ≤14 张、5.0 pro/flash ≤10 张
- **size 推荐「档位+比例描述」**：size 传 1K/2K/4K 档位、宽高比写进 prompt 自然语言由模型适配；成本 ∝ 像素数（4K 档≈2K 档 4 倍），按用途选档
- **组图模式（sequential_image_generation）**官方定位=漫画分镜/故事板一组关联图；若用它一次出一套状态谱系，prompt 必须写明数量与逐张状态（「生成4张……图1→图4」句式），参考图+生成图 ≤15
