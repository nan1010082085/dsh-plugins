# prop-studio（道具出图 · 独立素材类 · 随剧情演进）

道具与人物、场景并列的**第三类素材**：分层工程（人物层/背景层/道具层）里道具层独立——方便动画、位移、换道具、特写；同道具多镜多集复用，单独出图一次处处使用；特写镜头需要道具单独高清图放大不糊；造型锁定保证第一次出场和后面镜头一模一样不穿帮。**道具随剧情演进**（`道具名-状态`（示例占位）），不同道具状态本身就是看点——每个状态是独立素材。

## 何时使用

- 剧本条目产出后要出道具图/道具特写/道具状态变体
- 分镜块 `素材映射[]` 点名了道具资产需要建/补/重制
- 用户提到：道具出图 / 道具设定表 / 道具特写 / 道具状态 / 防穿帮

## 流程

0. **剧本拆解表（出图前必做）**：按 `references/prop-asset-system.md` §〇抓 4 类信息——文本直接描述（材质/新旧/痕迹）、剧情功能（特写/状态变化/伏笔/情绪）、归属角色信息（贴合人设）、世界观时代（规避穿越道具）；填拆解表逐行定稿后才出图
1. **关键性准入 + 建道具清单 + 分类判定**（按 `references/prop-asset-system.md` §一）：**只有关键性道具才出卡（2026-11-06 用户令）**——承载剧情/线索/身份/情绪/特写记忆点的才建资产出图；普通物件（一次性道具/路人手持/通用陈设）不出卡不出图，出视频时文字描述带过，省积分防冗余；再分类：
   - ✅ **单独出图**：手持/佩戴/可拿起放下（手机/伞/杯/书/武器/拐杖/饭盒）、会变化（开合的信封/撕碎的纸/半杯水）、要特写要动效（钥匙/照片/信物/车票）
   - ❌ **画进场景**：固定不动的装饰（壁画/地砖/吊灯/柜子/窗外树/固定抱枕）
   - 通用道具（人人可用）与角色专属道具分栏登记；`references/prop-asset-system.md` §二命名
2. **出图前置调研**：执行 `shared/pre-gen-research.md` 四步
3. **道具主图（t2i）**：按 `references/prop-prompts.md` 模板——白底/透明底 PNG；道具不需三视图（2026-11-06 用户令）：一张主视图为主，复杂道具按需加一处侧面/透视辅助图；**造型锚点短语写死**（花纹/形状/材质逐项，跨状态跨镜复述一字不差）；**大小比例参考入图**（如「与成年男性手掌对比」）
4. **状态变体（i2i 挂主图）**：随剧情演进的状态=独立素材（【合上的笔记本】【翻开第 3 页的笔记本】是两张图）；同光影同画风只改状态要素；旧状态退役不改图
5. **交付与对账**：写入 assets.json props[]（LOCKED 字段逐字，`shared/output-formats.md` §3）；按 `references/prop-asset-system.md` §六文件夹归档（通用道具/角色专属道具）；特写版+远景版两套输出；与分镜块 `素材映射[]` 对账——点名道具全挂
6. **校对+试嵌入（画完不能直接入库）**：①剧本对照校验（材质/新旧/标记逐条对剧本、隐藏细节在、多余原创设定删）②嵌入测试（PNG 贴进场景+人物图层：比例自然/光影融入不像贴纸/特写细节可读）——发「浮」=阴影方向或饱和度不匹配

## 硬闸与自检

- **关键性准入（2026-11-06 用户令）**：只有关键性道具才出卡（承载剧情/线索/身份/情绪/特写记忆点）；普通物件文字带过不出卡——不拦会浪费积分+素材库冗余
- **分类判定硬规则**：会被拿起/移动/特写/变化的才单独出图；固定装饰画进场景——判错方向=素材浪费或分层失败
- **造型锁定防穿帮**：锚点短语（形状/花纹/材质/颜色/尺寸）跨状态跨镜复述一字不差；AI 生成每款花纹形状都会漂——**提示词固定一套，状态变体走 i2i 挂主图 + 指令式编辑句（「保持造型、花纹、材质不变，将〔状态A〕改为〔状态B〕」）**，禁每状态重新 t2i（原「重绘幅度 0.3–0.4」已被火山官方 API 校正 2026-10：Seedream/即梦无 strength/denoise/重绘幅度参数，改动程度靠「保持 X 不变，将 Y 改为 Z」指令句控制）
- **刻字不进 AI 生成**：文字/刻字/标签一律先出无字版、后期手动加字——保剧本文字准确。小字真实口径（社区实测：smzdm 聚合/知乎）：大字/少字可直出（单块 ≤10 字可试，prompt 写死「文字清晰可读、笔画完整、无乱码」仅降概率不根治），4 个大字可对、20 个小字几乎必错，小字号/密集排版/中英混排错误率陡升——成片级文字默认后期叠字（原「AI 小字必乱码」绝对表述已按社区实测校正 2026-10）
- **痕迹克制**：使用痕迹/个人印记/剧情暗示只加剧本逻辑支持的（`prop-asset-system.md` §四）；剧本没写的不乱加设定，防与后续剧情冲突
- **比例基准=主角手掌统一比例尺**：全剧道具统一「和手掌对比」标注，防大小穿帮
- **状态=独立素材**：同道具不同状态分开存图分开命名；禁止一张图里混多个状态
- **比例参考在图**：每个道具图带比例参照物或比例标注，防剪辑时大小穿帮
- **广告闸**：道具无品牌无商标无包装特写（`shared/hard-gates.md` §6，过 `tools/brand_scan.py`）；真实商品道具一律素色化
- **花钱门**：扣积分出图走 `tools/credit_gate.py`；一枪一停、重制不夹带
- **调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）**：`watermark=false` 必设（默认 true 打「AI 生成」水印）、返回 URL 24h 失效即时转存、prompt 中文 ≤300 字——全参数见 `references/prop-prompts.md` §9
- 幂等自检：新道具与既有道具撞形（同款杯/同款刀）先查重再建

## 产出与格式

- **assets.json props[]**：字段名逐字 `shared/output-formats.md` §3.4 LOCKED 契约（`{名, 类别, 所属角色, 造型锚点, 状态[], image, 比例参考, 文件路径}`）
- **道具生图指令**：五段式道具版组装（`references/prop-prompts.md`），代码块交付
- **对账表**：道具 × 出镜镜头 × 状态 × 挂载节点，交 `shot-qa` 素材校验
