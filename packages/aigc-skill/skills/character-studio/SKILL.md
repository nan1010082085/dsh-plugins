# character-studio（人物出图 · 基础形象设定卡锚点制）

把剧本人物变成**跨镜同人**的图片资产：**基础形象设定卡**锁身份（三视图+头部特写+眼部特写合一，随剧本阶段演进；**表情板以设定卡为基础单独出指令**、**道具单独出卡（只有关键道具才出卡）**，2026-11-06 用户令），装扮变体人物卡/面部身份卡做可替换模块（i2i 挂设定卡同机位）；**服装饰品（头戴/耳饰/颈饰等）随人物图**——直接画在图上，不单独出服装/饰品图、不建独立资产。设定卡是出视频时的角色参考图唯一入口。人物建模质量是留存三主轴之一——本 skill 是它的唯一出口。

## 何时使用

- 剧本条目产出后，要出人物图、三视图、装扮变体人物卡、表情板、立绘
- 分镜块 `素材映射[]` 点名了人物资产需要建/补/重制
- 用户提到：人物出图 / 三视图 / 表情表 / 服装设定 / 立绘 / 角色一致性

## 流程

1. **读剧本建人物清单 + 出场顺序表**（策划层标记，下游照点位执行；行业工艺总纲见 `shared/manhua-production-standard.md`）：从剧本条目 `人物[]` 提取角色，外貌锚点一字不差；建**出场顺序表**——每人标注首次出场集/镜、是否加名条（主要角色加、龙套不加）；人设卡按行业完整字段：外貌固定设定细到脸型/眼型/瞳色/唇形/发型细节、固定穿搭套装每套配图、**禁止项**（禁双眼皮变单眼皮/发色乱变类）、**角色色卡**（每人固定主色）、**表情库 6–8 种**（平静/微笑/委屈/愤怒/震惊/含泪/冷漠…，不止 2×2）、三角度参考；按 `references/character-asset-system.md` §一 登记 characters[]/outfits[] 字段
2. **出图前置调研（固定工序，禁止跳过）**：执行 `shared/pre-gen-research.md` 四步：检索 → 对齐核心要素（主体+三视图+表情+多套服装+风格质感+跨镜一致性）→ 出指令 → 沉淀回风格 skill
3. **基础形象设定卡（身份锚，t2i·合一排版）**：按 `references/character-prompts.md` §1.1 骨架——**一卡=三视图（标准A站姿、无动作）+头部特写+眼部特写**（画布实证版式）；**表情板单独出指令**（i2i 挂设定卡，6–8 格绑定角色核心识别点）；**道具单独出卡走 prop-studio（只有关键道具才出卡）**；服装饰品（头戴/耳饰/颈饰等）随人物图直接画上、不单独出图（2026-11-06 用户令），纯白底、影棚柔光无阴影；抽卡择优后**锁定** visual_id。**基础形象随剧本阶段演进**：造型/外观因剧情变化（换装/负伤/装备/形态）即出新卡（「角色-基础形象A/B/C+阶段范围」命名），不是全剧一张；**本卡=该阶段后续所有分镜/出视频指令的角色参考图唯一入口**
4. **装扮变体卡 / 表情板（i2i 挂设定卡）**：按 `character-prompts.md` §1.2/§1.3 骨架，强制同光影/站姿/机位；服装逐件写死+配饰（头戴/耳饰/颈饰）随身穿戴画在人物图上、不单独出饰品图（2026-11-06 用户令）；表情解剖式写法。**多视图参考卡（出视频挂载版）/ 服装变体轴 / 个人识别锚 / 生物宠物与鬼怪两态设计**按 `references/multiview-creature-spec.md`（7 视图卡版式、`角色名-服装变体` 命名、分色变体=角色区分、比例锚逐镜重复、跨视图一致性核对清单）
5. **面部身份卡 / 色卡**：按 §1.4；近景与调色对齐用
6. **交付与对账**：写入 assets.json（LOCKED 字段逐字，见 `shared/output-formats.md` §3），与分镜块 `素材映射[]` 逐镜对账——露脸角色全挂

## 硬闸与自检

- **一致性两层控制**（`shared/prompt-formula.md` §二）：人物基准层锁身份 → 场景融合层锁光影——两层缺一必漂。天花板如实（社区横评+官方论文，见 `references/character-asset-system.md` §五）：参考式参考条件≠身份保证，长期一致性靠设定卡唯一入口+每镜挂资产+崩坏镜重生成兜底
- **t2i/i2i 分工**：主体 t2i 文字控构图；服装/表情/立绘 i2i 挂主体 + 构图硬锁句（防参考图排版被锚走）
- **广告闸**：手持物/服装商品「素色无品牌+禁包装特写」，出图前后过 `tools/brand_scan.py`
- **花钱门**：扣积分的出图走 `tools/credit_gate.py`（报价→用户批→跑）
- **调用硬要求（官方：火山方舟《图片生成 API》2026-10-14）**：`watermark=false` 必设（默认打「AI 生成」水印）、返回 URL 24h 失效即时转存、prompt 中文 ≤300 字——全参数见 `references/character-prompts.md` §2
- **出图验收清单**（`character-prompts.md` §4）逐张过：五官锚点/机位正交/服装逐件/手部完整/无品牌/表情差异
- **设定卡避坑五条**（`character-prompts.md` §1.1）：A站姿无动作/同角色配色结构统一/纯白背景/表情板独立指令绑识别点/本卡即角色参考唯一入口
- 一枪一停、重制不夹带、验真只认新产物（`shared/hard-gates.md`）
- 违禁词/裸英文过 `tools/prompt_selfcheck.py`（后端方言长度按 `shared/backends.md`）

## 产出与格式

- **assets.json characters[]/outfits[]**：字段名逐字 `shared/output-formats.md` §3 LOCKED 契约（`name/visual_id/three_view/face_card/expressions[]/outfits:[{名, three_view, 配饰}]`）
- **人物生图指令**：五段式组装（`shared/prompt-formula.md` §四），代码块交付，按目标后端方言
- **对账表**：角色 × 出镜镜头 × 挂载节点，交 `shot-qa` 素材校验
