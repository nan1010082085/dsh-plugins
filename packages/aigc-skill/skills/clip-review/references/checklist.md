## 成片硬伤扫描（最低覆盖，2026-10-31 入库）

> 五项核验之外的**成片级硬伤**逐项快扫——行业 QC 最低覆盖集 + 平台官方缺陷清单，每条成片必过：

| 项 | 判定 | 来源 |
|----|------|------|
| 黑帧 | 无画面黑帧段 | 【行业：framesense.io】 |
| 定帧 | 画面卡死 / stuck media | 【行业：framesense.io】 |
| 静音/爆音 | 静音段、爆音/咔哒 | 【行业：framesense.io】 |
| 响度/峰值 | 响度异常、峰值超标 | 【行业：framesense.io】 |
| 规格 | 分辨率/帧率/容器不符 | 【行业：framesense.io】 |
| 字幕文案 | 错别字/语法错误（AI OCR + 文案校对） | 【行业：framesense.io】 |
| 音画相关 | 配音与画面不相关、口型错位 | 【官方：视频号 5.11.4】——**平台违规项**，不只是美观问题 |
| 官方低质缺陷 | 画质模糊/内容不完整/音画不相关/内容重复/过度剪裁/上下颠倒/黑边/扭曲花屏 | 【官方：视频号 5.14.2】——唯一平台官方级成片缺陷分类 |

## 质量维度命名对照（VBench 16 维 · 学术：VBench，CVPR 2024 Highlight）

| 我们核验项 | VBench 维度 | 备注 |
|-----------|------------|------|
| ② 脸与服装一致性 | subject identity inconsistency（主体一致性） | 跨镜同脸同人同口径 |
| ④ 运动与姿态 | motion smoothness（运动平滑） | 崩坏镜判定 |
| ①/⑤ 空间与光影 | spatial relationship（空间关系） | 空间关系错位/代景错 |
| （原缺口）时序闪烁 | temporal flickering（时序闪烁） | 五项未覆盖 → 由「成片硬伤扫描」定帧/闪烁项补位 |

（VBench 将视频生成质量解耦为 16 个可解释维度并用人类偏好标注对齐；此处仅列与本清单直接对应的维度，命名对齐学术口径便于跨工具对照。）

## 核验报告格式

**逐项 PASS/FAIL + 时间码 + 严重度三件套，禁止只给加权总分**【行业：framesense.io——AI 视频 QC 通行形态；严重度 Critical=必重生成 / Warning=可后期补救 / Info=记录】。每项缺陷带时间码（mm:ss）定位。

示例：`核验：①穿模 过（接触面分离清晰）②脸 过 ③道具 ✗形态漂【示例占位】 ④运动 过 ⑤光 过｜归因：③→参考图权重弱（道具图特写被场景稀释）→回流通道②：分镜道具暴露面设计规避`
