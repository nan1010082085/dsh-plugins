# clip-review（成片核验与回流）

虚拟导演出片后的调优闭环：**核验 → 归因 → 回流**。上游 `video-producer` 产成片，本 skill 判质量、找根因、把教训变成规则——下一镜自然变好，不靠二次调。

## 何时使用
- 每条成片下载后必过本 skill（抽帧核验）；用户报「穿模/假/漂」类问题时按归因矩阵定位。

## 流程（三步）
1. **抽帧核验**（references/checklist.md 五项核验 + 成片硬伤扫描 + VBench 维度对照）：首/中/尾帧 + 接触区放大（crop 放大看手腿交界）。
2. **缺陷归因**（references/defect-attribution.md 矩阵）：每缺陷定位到层——分镜写法 / 参考图配比 / 模型能力上限 / 素材缺口——**层归错了修也白修**。
3. **回流三通道**：①skill 规则（对照稿交用户批后写入，禁止擅改）②分镜模板/资产映射（直接改文本层）③素材补建清单（登记待建禁出片）。产出核验报告（格式见 checklist：逐项 PASS/FAIL + 时间码 + 严重度三件套，禁只给加权总分【行业：framesense.io】）。

## 硬规
- **一次翻车=一条新规**：每个归因结论必须落成规则或模板修正，禁止同坑二翻。
- **禁止积分试错**：缺陷修在文本层（分镜/规则），不许靠重出碰运气；模型能力上限类缺陷走设计规避，不硬碰。
- 核验不过=崩坏镜，按 video-producer 崩坏镜口径单独重生成，不整段重做。
