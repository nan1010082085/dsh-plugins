# style-cg-refined（半写实精致 CG 渲染 · 主风格）

**风格定位**：角色设计允许风格化（夸张比例/科幻造型），但**渲染必须写实**——真实材质质感、自然光影、电影级镜头语言。一句话：**设计可以假，光和材质必须真**。目标观感=电影剧照级的精致 CG，杜绝游戏 CG 感、塑料感、动作僵硬。（本风格 2026-10-27 应用户要求由 3D 卡通渲染 cel-shading 升级而来，取代其主风格位。）

## 何时使用

- 剧目锁定半写实精致 CG 风格（本套件默认主风格）
- 用户提到：半写实 / 精致 CG / 电影质感 / 超写实渲染 / 即梦出片风格
- 出图/出视频需要取「风格段」时

## 流程

1. **确认风格锁**：一部剧 1 种风格全剧不换；本风格一旦锁定，全片所有资产（人物三视图/服装/表情/场景/视频）共用
2. **取风格段**：从 `references/style-profile.md` 取风格锁模板（中英）+ 高效组合，按 `shared/prompt-formula.md` §四五段式组装
3. **按后端方言调**：画质词/负面词/长度按 `shared/backends.md`（本风格的相机词在即梦/Flux/MJ 都有效）
4. **材质词入正文**：本风格的核心武器是具体材质词（哑光皮革/磨砂金属/织物纹理/胶片颗粒）——写进内容段，不靠画质词堆
5. **翻车点自检**：对照 `references/style-profile.md` 翻车点表逐条过

## 硬闸与自检

- **禁游戏 CG 感**：禁「游戏画面/塑料皮肤/无纹理平滑/过度美化失真」；皮肤要写质感（细腻真实皮肤纹理），材质要写具体
- **禁卡通写实混写**：本风格禁入 cel 系词（赛璐璐平涂/粗描边/色块平涂/扁平）——那是 style-anime / style-pixar 的武器，混用必崩
- **相机词是本风格的合法武器**：IMAX 胶片/Panavision 镜头/焦段光圈/胶片型号/动态模糊可入提示词（与 cel 系相反）
- **光影写实**：光源方向/色温/曝光规则（高光不过曝、暗部留细节、明暗过渡自然）逐镜复制（光影四件套）
- 画质词分平台（`shared/backends.md`）；广告闸/花钱门照常（`shared/hard-gates.md`）
- 出图前置调研（`shared/pre-gen-research.md`），新结论沉淀回 `references/style-profile.md`

## 产出与格式

- **产出**：风格段文本（可直接嵌入五段式组装 / 出视频指令【氛围与画质】段）
- **沉淀**：调研/实战发现回写 `references/style-profile.md` 翻车点表，标日期与来源
