# style-photoreal（写实摄影 · 风格段）

剧目风格锁为「写实摄影」时的风格段出口。核心是机型+镜头+光圈+胶片/调色四件套，不是 quality soup。风格段 = 风格锁句 + 高效组合词组 + 后端画质/负面词尾巴。

## 何时使用

- 剧目风格锁为「写实摄影 / 真实影像质感」时，所有出图/出片提示词取本风格段
- 用户问：写实照片感 / photorealistic / 胶片感提示词怎么写
- 新剧立项定风格、或人物三视图/场景空镜/分镜成片需要统一风格段

## 流程

1. **确认风格锁**：一部剧只锁 1 种风格，全剧不换（与 `shared/director-styles.md` 全剧基调对齐）；先定调性（商业精致 / 80s 复古 / 2000s 卡片机 / 纪实粗糙）
2. **取风格段**：从 `references/style-profile.md` 取「风格锁模板」（中/英各一版）+「高效组合」四件套词组，组装风格段
3. **按后端调方言**：画质词/负面词按 `shared/backends.md` 与 style-profile「负面词与画质词策略」分流——删 masterpiece/8k/RAW，换机型镜头胶片词；MJ 加 `--style raw`
4. **总装**：风格段嵌入五段式组装（`shared/prompt-formula.md` §四），与人物锚点段、场景锚点段拼接
5. **翻车点自检**：对照 style-profile「翻车点与对策」逐条过，重点查 quality soup 与手部/皮肤缺陷

## 硬闸与自检

- **禁卡通/动画词混入**：cel-shaded / cartoon / animated / Pixar 等动画词不进写实风格段（反向风格污染）；与 cel 系 skill 的写实词禁令互为镜像
- **禁知名角色名/受保护角色**：风格描述≠复制角色，禁写真实明星/公众人物名与受保护形象
- **画质词按后端分流**：禁统一挂 8k/RAW/ultra-detailed/masterpiece——堆叠无益甚至带「AI 味」，SDXL 上 masterpiece 拉向绘画、MJ 完全忽略内联质量词【社区实证·Promgrammer】（研究 §3/§4-5）
- **风格污染警告**：霓虹赛博光、皮克斯圆润夸张比例不进本风格段；一剧一风格不混搭
- **出图前置调研**：新疑问先走 `shared/pre-gen-research.md` 四步，结论回写 style-profile.md

## 产出与格式

- **产出 = 风格段文本**（中文版 + 英文版，可直接嵌入五段式组装的风格位）
- 风格段固定三件：风格锁句（整段复制）+ 高效组合词组（四件套按需摘取）+ 后端画质/负面词尾巴
- **沉淀规则**：调研/实战新发现回写 `references/style-profile.md`，标注来源；未查证处标【推测】
