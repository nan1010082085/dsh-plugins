# 原创操作细则（idea-workflow）

> `idea-to-drama` 的操作层细节。分集规则本体在 `shared/split-methodology.md`（故事单元/每集结构模板/两核心验收），本文件不复述，只写**想法进场怎么落地与怎么验收**。
> 根原则重申：由想法出发进行创作——用户想法是唯一事实源，提炼 + 校准 + 补完成戏，不偏题不注水。

## 一、想法提炼与提问模板（最多 2 问）

先读想法，把词面信息拆成四个意向位：**题材 / 受众 / 单集时长意向 / 集数盘子**。读得出的意向位不再问。

**提问模板（任选其一或其二，总数 ≤2 问，一问可带两个子项）：**

1. 「这个故事偏哪类受众——女频情感还是男频爽感？大致想要几集的盘子？」
2. 「单集时长有倾向吗（还是交给我按正片 60–120 秒自动成型）？有没有必须保住的桥段或人设？」

**补默认并声明**：没问到也没读出的意向位，自己推理补默认，逐条声明「假设：…（依据：…）」，用户可改。默认表：

| 意向位 | 默认值 | 依据 |
|--------|--------|------|
| 题材 | 从想法词面推（职场/复仇/甜宠/玄幻…） | 想法自带的场景与关系词 |
| 受众 | 女频向 **25–44**（25–34 核心、35–44 第二主力）；题材指向男频则改 | 【行业报告·艾媒 2025 + 明略 2026 + DataEye 2025】（2026-10-31 校准：原「女频 18–35」，把 35–44 第二主力整个切掉；全市场性别 ≈52:48 均衡，女频偏斜是红果等免费平台供给现象（女 68%），付费向勿按纯年轻想当然——45+ 付费意愿强【社区转述·谨慎】） |
| 单集时长意向 | 不设，正片 60–120 秒自动成型（30–60 秒仅引流切片） | `shared/split-methodology.md` 第一节（2026-10-31 校准：原 30–120，30 秒档低于主流正片口径） |
| 集数盘子 | 一季 5–10 集量级，按故事单元自然成型 | 故事容量，不先定数再切 |

**硬规矩**：追问总数 ≤2，不许刷屏；也禁止闷头替用户做主不吭声——补的默认必须亮出来。用户想法里的**核心要素**（主角设定、关键桥段、名场面点子）此时就逐条记下，它们是后面「想法命中率」的对照清单。

## 二、搜索关键词构造法（题材词 + 冲突词 + 平台词）

每条检索串由三段拼成，缺段就补通用词：

```
题材词 + 冲突词 + 平台词
```

- **题材词**：想法的核心类型与场景词（如「都市 职场 复仇」「重生 打脸」）——**题材标签本身就是观众的冲突预期**（逆袭/打脸虐渣/重生是市场验证的第一冲突公式，热力与偏好数据见 §八）【行业报告·DataEye 2025 + 明略 2026】；
- **冲突词**：想看的对抗类型（如「反转 名场面」「冲突结构」「节奏 钩子」「爽点」）；
- **平台词**：投放语境（如「短剧 漫剧 爆款」「微短剧 完播率」「抖音 短剧 热榜」）。

三类检索目标各跑一组，产物分别记：

| 检索目标 | 看什么 | 用在哪 |
|----------|--------|--------|
| 同类题材爆款 | 同题材作品把什么桥段做成了名场面 | 校准名场面落点 |
| 爆款冲突结构 | 冲突密度、反转节奏、钩子套路 | 校准每集看点/钩子写法 |
| 市场偏好 | 受众口味、开头多久进冲突、哪类钩子留人 | 校准开头 5 秒与结尾钩子 |

**红线**：搜索结果只做校准参考——**拿来的是「什么冲突/什么钩子吃香」，不是别人的故事**；禁抄设定、禁搬运情节、禁引名台词。检索不可用或搜不到时，声明「未检索到，按通用套路校准」，用通用戏剧常识补位，不许假装调研过。

## 三、logline 模板（主角 + 目标 + 阻碍 + 赌注）

```
【主角】为了【目标】，必须对抗【阻碍】，否则【赌注】。
```

- **主角**：带身份锚的一句话人设（谁、什么处境），与人物小传同名；
- **目标**：具体可达成的一件事（不是「变强」这类空话）；
- **阻碍**：人/规则/自身，必须能立成对抗关系；
- **赌注**：输了会失去什么——赌注不痛，冲突不成立。

**logline 四件套的业界共识口径（2026-10-31 入库）**【专业媒体·Creative Screenwriting《9 Components Of The Perfect Logline》+ Final Draft】：

- 定义（可直接引用）：「A logline is **a single sentence of about 35 words** that defines the story's central conflict through context/setting, a flawed main character & their opposition, triggering events, goal, stakes, and tone.」——多来源收敛到同一四要素 **protagonist / goal / obstacle / stakes**，与上方模板逐项同构。
- 五件套展开：主角 + 想要什么 + 为什么想要 + 谁/什么不许他得到 + 得不到会怎样（后两者 = 阻碍/赌注）。
- 取舍原则：只写中心冲突；多场景/支线/次要人物留给 synopsis；内部冲突和华丽描写砍掉；tone 必须与实际故事一致；通常不写主角名字（众所周知者除外）。
- 量化上限：约 35 words；中文折算 60–80 字内**【经验·内部·折算】**（报告自定折算，非行业明文）。

验收：logline 一句话讲完且能罩住想法核心要素；遮住想法能从 logline 反推出同一个故事 = 合格。logline 立不住就回第 1 步补想法理解，不许跳过直接写剧本。

## 四、多集结构与集数规划（建置 → 升级 → 高潮）

逐集按**每集结构模板**落位（建置 → 升级 → 高潮，模板本体见 `shared/split-methodology.md` 第四节，此处不复述），操作序同源（`shared/split-methodology.md` 第五节 2–7 步）：

1. **标转折点**：在多集结构里按「发现线索 → 遭遇阻碍 → 突破/反转」标情节点；标不出转折点的段落 = 水段，砍掉或并入相邻单元。
2. **分组节拍**：节拍按转折点/情绪高潮归入微事件单元，每单元 1–3 场景。
3. **排集**：微事件落位成集——**集数按故事单元自然成型**，不是先定集数再切故事。单元装不下就拆、装不满就并；为凑集数摊薄故事、为省集数硬压故事都算分集失败。
4. **换算锚只校节奏**：1 分钟 ≈ 台词 200–240 字做初算锚（配音口径；动作/说明文本另计）（`shared/split-methodology.md` 第一节），先按故事单元拆、再校对节奏，顺序不能反（2026-10-31 校准：原 200–400 字/分钟，400 上限超出任何播音/配音口径、无行业出处——【社区/行业经验·配音口径收敛】）。
5. **连贯检查**：开头承接上集 + 结尾钩子在场 + 主线贯穿（同一核心目标，可用倒计时/任务清单串联），过了才定稿。
6. **时长自然成型**：由节拍密度得 `时长秒`（正片 60–120 自动；30–60 秒仅引流切片），超界说明单元拆得不对，回第 3 步重排，禁止注水或砍戏硬压（2026-10-31 校准：原 30–120）。

**结构节拍参照：《救猫咪》(Save the Cat) 15 节拍表（2026-10-31 入库）**【书籍·Blake Snyder《救猫咪》，官方 beat-sheets https://savethecat.com/beat-sheets + StudioBinder 页码详解 https://www.studiobinder.com/blog/save-the-cat-beat-sheet/ 】：

「story beat」= 一个在关键时刻转变角色与故事的单一故事事件，是结构上的检查点；落页按 110 页剧本给出，是**相对位置**，可按目标时长/集数等比缩放。logline → 节拍表 = 「先骨架后扩写」的标准路径。

| # | 节拍 | 落页 | 功能 |
|---|------|------|------|
| 1 | Opening Image 开场画面 | p1 | 一帧定调（look and feel） |
| 2 | Theme Stated 主题陈述 | p5 | 常由他人对主角说出、主角尚未领悟 |
| 3 | Set-up 铺垫 | p1–10 | 旧世界/现状 + 相关人物 |
| 4 | Catalyst 激励事件 | p12 | 打破现状（=inciting incident） |
| 5 | Debate 犹豫 | p12–25 | 是否出发的怀疑（≈英雄之旅「拒绝召唤」） |

| 7 | B Story B 线 | p30 | 常为爱情线，承载主题 |
| 8 | Fun and Games 玩耍时光 | p30–55 | 「前提的承诺」兑现段 |
| 9 | Midpoint 中点 | p55 | 得到或未得到所求均有后果；赌注抬高 |
| 10 | Bad Guys Close In 坏人逼近 | p55–75 | 外部反派或内部裂痕收紧包围 |

## 五、人物小传字段（与 `人物[]` 呼应）

每个有名有姓、露脸出场的人物建一条小传，字段固定：

| 字段 | 内容 | 呼应 |
|------|------|------|
| 姓名 | 全剧统一命名 | `人物[]` / assets.json 的 `characters.name` |
| 三级定位 | 主角 / 配角 / 路人 | 分集出场权重 |
| 目标与阻碍 | 个人目标、与谁对抗 | 驱动该人物的冲突 |
| 说话方式 | 口癖/敬语/长短句/称呼 | 剧本「人物靠对话」逐人对齐防串味 |
| 关系与演进 | 与主角关系、在哪几集变化 | 分集里关系戏的落点 |

- 命名可挂资产：露脸角色全进 `人物[]`，逐人可挂资产（对齐 assets.json 的 `characters.name`）。
- 说话方式在小传里记死，写对话时逐人对齐；性格靠对话与选择体现，禁止旁白「他是个冷漠的人」一类交代。

> 来源注记（2026-10-31）：本字段表系**社区/教学经验口径**【社区】，非教科书标准——《故事》《救猫咪》原书均无「人物小传」标准字段表（核验空白）。社区旁证：一句话角色简介（character logline）与段落小传分层；小传要写出「是什么让这个角色不同于其他角色」，先梳理人物脉络防止「把人物写飞」。

## 六、原创剧本两核心的具体验收标准

### 灵活叙事（节奏紧凑、镜头精炼、快速成片）

- **冲突密度高**：每集至少 1 个正面冲突 + 1 个钩子；单集节拍里纯过渡/纯说明的节拍占比不超过三分之一。
- **每集钩子**：结尾必留 Cliffhanger，且**第 N 集悬念 = 第 N+1 集钩子**【社区·DramaSo】；钩子类型参考：新威胁现身 / 关键信息只说一半 / 选择摆在面前未作答 / 反转打脸前一刻；遮住钩子能自然猜到下集走向 = 钩子不合格，回炉。
- **砍水戏**：重复情绪、无目标闲聊、纯赶路/纯回忆的场景砍掉或并入有冲突的场景。
- **每场戏直接可拆镜头**：写成可分镜的视听事件（谁在哪做什么说什么），不含「一段时间过去了」一类不可拍叙述；产出即进 `storyboard-director` 不返工。

**黄金秒链（2026-10-31 入库）**【社区·数艺社 https://www.163.com/dy/article/L30RCS1005340TH8.html + DramaSo https://drama.so/zh/blog/short-drama-script-structure + Filmustage 转引；完播口径佐证【官方媒体·文汇报/光明网 https://e.gmw.cn/2026-06/23/content_38843027.htm 】】：

`0–3 秒黄金钩子` → `10 秒内交代核心矛盾+人物关系+主角目标` → `30 秒内第一次反转/爽点` → `每 20–30 秒一个情绪节点` → `结尾 5–10 秒强钩子（= 下集钩子）`。

- **钩子三型**：直接冲突型 / 强悬念型 / 极致反差型【社区·数艺社】。
- **开场铺垫 >10 秒（环境/心理描写）= 直接划走**——低完播三大坑之首。
- 旁证：TikTok 官方创意指南「点击率最高的视频超 63% 在前 3 秒亮出关键信息」（**经 DramaSo 转引，原文未核**）；「黄金 30 秒」旧口径已被「完播率」部分取代——**集内钩子保点击、整集质量保完播**，两者都要【官方媒体·文汇报】。
- **低完播三大坑**（负面清单）【社区·数艺社】：①开场铺垫超 10 秒；②结尾无钩子（转下一集数据暴跌）；③长时间持续虐主角无反击缓冲（直接弃剧）。

**单集节奏骨架（60 秒七节拍，参照非硬闸）**【社区·DramaSo（自称脱胎《救猫咪》15 节拍压缩成 7 节拍）】：

| 节拍 | 时间 | 任务 |
|------|------|------|
| 钩子 | 0:00–0:05 | 引爆一个必须看到答案的问题 |
| 铺垫反转 | 0:05–0:15 | 交代人物场景后立刻打破第一个预设 |
| 小悬念 | 0:15–0:20 | 顶住信息流第一流失点（Filmustage 转引口径） |
| 升级 1 | 0:20–0:30 | 权力易位（有人失去筹码） |
| 升级 2 | 0:30–0:40 | 逼出收不回的公开抉择 |
| 反转 | 0:40–0:50 | 新信息给此前一切重新上色 |
| 悬念 | 0:50–1:00 | 定格在下一集开场要回答的问题上 |

- 扩展规则：扩到 90/120 秒只加第二幕升级节拍（每 15–20 秒加一个），**第一幕永不加长**。
- 悬念五型收尾：揭示式 / 打断式 / 抉择式 / 反转式 / 威胁式。
- 升级测试（开拍前机械自检）：三列审查——谁握权力、观众知道什么、什么处于危险中；**每个节拍至少挪动一列**。

### 剧本理解（原创版 = 想法命中率）

- **想法核心要素逐条有落点**：第 1 步记下的核心要素清单，逐条对照到具体集数/节拍——想法要的桥段、人设点、名场面点子，必须在剧本里演出来，不许扩写着扩写着丢了。
- **扩写补完不偏题**：搜索校准、补默认、加戏都围绕想法转；与想法无关的支线砍掉，偏离想法的「好点子」不加。
- **验收方式**：交付时附「想法要素 → 落点集数」对照表；对不上的回第 3 步补结构或回第 4 步补戏，缺落点不交付。
- **动机链与逻辑连续性 = 留存硬指标**（2026-10-31 入库）：中后期弃剧负面 73.5% 集中于「剧情逻辑崩塌」「人设矛盾」，且口碑杀伤更持久【行业报告·明略 2026】——逐集查人物动机链与前后逻辑，矛盾即打回。

## 七、交付前快检（逐集 + 全局）

- [ ] 集首 3 秒钩子在场、10 秒内立矛盾、30 秒内首爆点（黄金秒链，第六节）；起手即动作/对话/异常
- [ ] 结尾钩子在场、句号收尾、遮住不能猜到下集；第 N 集悬念 = 第 N+1 集钩子
- [ ] 每集至少 1 个正面冲突，纯过渡节拍占比 ≤1/3；无低完播三坑（铺垫 >10 秒/无尾钩/持续虐主无反击）
- [ ] 每集至少一个价值翻转（McKee 场检验：场首场尾价值电荷必须变化，纯 exposition 场应删——`shared/script-craft.md` §二-8）【书籍·McKee《故事》】
- [ ] 性格全在对话与选择里，无旁白交代（第五节）
- [ ] 想法核心要素逐条有落点，对照表已附（第六节）
- [ ] `时长秒` 正片 60–120 且自然成型（30–60 仅引流切片）；集数按故事单元成型，无注水无摊薄（第四节）
- [ ] 单集 1–3 场景、一集一个微事件、集数连续（`shared/output-formats.md` 第 1 节约束）
- [ ] 台词/旁白/字幕过 `tools/brand_scan.py`，无真实品牌（`shared/hard-gates.md` 第 6 节）
