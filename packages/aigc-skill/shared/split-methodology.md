# 拆分与改编方法论（split-methodology）

> 2026-10-27 用户供，`novel-to-drama` 与 `idea-to-drama` 两 skill 共用。
> 根原则：**由小说出发进行改编**——小说是唯一事实源，改编 = 取尽 + 补完 + 扩写成画面，不删不缩水、不脱离原著自创。
> 字数换算只是初算锚，**剧情刀口优先**；最终分集由故事单元与时长区间（正片 60–120s）自然决定。

## 一、换算锚（参考非定值，剧情刀口优先）

- 微短剧剧本 **1 分钟 ≈ 台词 200–240 字**（对话密集、动作精简；配音口径，动作/说明文本另计）。（2026-10-31 校准：原 200–400 字/分钟，400 上限 ≈6.7 字/秒超出任何播音/配音口径、无行业出处——【社区/行业经验·配音口径收敛（库库/知乎好声音配音/百度文库）】）
- 一章 **2000–4000 字** 参考拆 **3–5 集**（1–2 分钟/集）或 **2–3 集**（3–5 分钟/集）。
- **字数只做初算锚，禁止按字数硬切**：先按故事单元拆、再用字数校对节奏，顺序不能反。
- **单集时长自动决定，正片 60–120 秒区间**：由拆分出的剧情节拍与分镜自然成型，**不硬凑、不牵强**——不为凑时长注水、不为压时长砍戏。60–120s 时长自动成型，禁止硬凑；30–60 秒只用于引流切片，不作正片集。（2026-10-31 校准：原 30–120 秒/集，30 秒下限低于主流正片口径——【社区共识·DramaSo/数艺社/知乎一致（60 秒卡位为最小正片单元）】，平台审核规则明文未见）

## 二、按故事单元拆，不按字数

- **一集 = 一个微事件**：明确目标/冲突 ＋ 起承转合（哪怕很短）＋ 结尾钩子（Cliffhanger）。
- **单集 1–3 个场景**；一章若铺开 5 场景，按转折点/情绪高潮分组归集。
- **拆分刀口跟情节点走**：发现线索 → 遭遇阻碍 → 突破/反转——先标出转折点，再按转折点给场景分组。
- **禁止「一章 = 一集」机械映射**：分集单元是剧情节拍/名场面，不是章节。一集可跨多章取材；一章名场面密度高也可拆成多集。一章文字直接压一集「表达不够」= 分集失败。
- **连贯标题必须同集**；名场面独立成集并加爆点。
- 每集必须装满戏剧容量（冲突/钩子），装不满就与相邻单元合并。

## 三、连贯改编技法

1. **叙述 → 视听**：心理/背景描写转成动作、表情、潜台词、环境细节。「他很害怕」→「手心出汗、后退一步、声音颤抖」（与分镜创作的情绪可视化同源）。
2. **结尾必留钩子**：每集结尾挂 Cliffhanger；原文结尾平缓就**调顺序，把后面的冲突提前**。
3. **人物靠对话不用旁白**：说话方式/性格通过对话与选择体现，禁止旁白交代性格。
4. **开头 5 秒抓人**：慢热开头重构成动作/对话直入，前 5 秒必须给到悬念或冲突。
5. **主线贯穿**：多集同一核心目标，可用倒计时/任务清单串联；每集开头自然承接上集。
6. **保留原作梗与名台词**（名台词 ≤20 字照引——≤20 字系**【自定 house rule·无行业出处】**，2026-10-31 校准标注：检索无任何行业/书籍给出台词字数上限），原著人物/伏笔/名场面不走样。

## 四、每集结构模板

| 位置 | 内容 |
|------|------|
| 第 1 集 | 建置目标 ＋ 第一冲突 ＋ 悬念 |
| 中间集 | 冲突升级/受挫 ＋ 更危急的钩子 |
| 末集 | 高潮解决 ＋ 收尾，或引向下一章 |

**每集撰写后过连贯性检查**（开头承接上集 + 结尾钩子在场）再定稿。

## 五、操作步骤（逐卷/逐章）

1. **拆解**：逐卷精读——人物盘点（主角/配角/路人三级）、人物弧线与关系演进、伏笔、名场面、爽点/冲突密度分布。
2. **标转折点**：按「发现线索→遭遇阻碍→突破/反转」在章节里标出情节点。
3. **分组场景**：把场景按转折点/情绪高潮归入微事件单元（每单元 1–3 场景）。
4. **排集**：微事件落位成集，跨章取材/一章拆多集按需，换算锚校对节奏。
5. **逐集撰写**：按每集结构模板写剧本条目（字段契约见 `shared/output-formats.md`）。
6. **连贯检查**：开头承接 + 结尾钩子 + 主线贯穿，过了才定稿。
7. **时长自然成型**：由节拍与分镜得出 `时长秒`（正片 60–120 自动；30–60 秒仅引流切片），不硬凑不牵强。

## 六、两核心验收（剧本产出标准）

- **灵活叙事**：节奏紧凑、镜头精炼、快速成片——冲突密度高、砍水戏、每场戏直接可拆镜头、产出即进分镜不返工。
- **剧本理解**：深度理解、读懂每一份剧本——原著人物/伏笔/名场面不走样，保留原作梗与名台词（≤20 字，【自定 house rule·无行业出处】）。
