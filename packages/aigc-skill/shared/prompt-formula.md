# 生图指令通用公式（人物 × 场景 × 后端无关）

> 人物 skill 与场景 skill 共用的公式层。风格段从对应**风格 skill** 取（style-cg-refined 主风格 / style-anime / style-pixar / style-cyberpunk / style-photoreal）、光影段从 `lighting-system.md` 取、方言（长度/负面通道）按 `backends.md` 切换；本文件只管**公式、一致性控制、景别词表、组装**。

## 一、经典七要素公式

任何生图指令（中/英文、任何后端）都按此顺序拆解：

```
[主体人物描述] + [动作与状态] + [服装与细节] + [场景环境] + [构图与景别] + [光影与色调] + [画质与风格]
```

| 要素 | 写什么 | 示例 |
|------|--------|------|
| 主体人物 | 国籍/年龄句首硬锚 + 五官锚点 + 发型发色 + 肤色基调 | 一个 20 多岁的中国女性，清秀五官，天然黑色长发 |
| 动作与状态 | 一个动作 + 一个表情（情绪可视化，禁「很伤心」式抽象词） | 温和地微笑着，手里拿着一个复古陶瓷咖啡杯 |
| 服装与细节 | 逐件写死：款型+颜色+面料+配饰 | 米色针织衫，细腻纹理 |
| 场景环境 | 空间 + 关键道具 + 背景处理 | 洒满阳光的咖啡馆木窗边，绿植，背景虚化 |
| 构图与景别 | 景别 + 视角（见 §三词表） | 中景，平视视角 |
| 光影与色调 | 光源方向 + 色温 + 质感 | 柔和清晨阳光，暖色调，电影级光影 |
| 画质与风格 | 风格 skill 的描述句 + **分平台画质词** | ⚠️ 8k/RAW/masterpiece 是模型相关弱偏置：Booru 动漫模型有效（≤3 个）、SDXL 写实反噬（换相机词：机型+镜头+光圈+胶片）、Flux/MJ/GPT/即梦=噪声删掉换具体材质词 |

规则：
- **七要素顺序即权重顺序**——越靠前越被模型优先执行；主体永远第一
- 要素之间逗号分隔、句式短平快；不要长从句套长从句
- 生图只写**固定景别**，不写运镜词（运镜是视频分镜层的事，见 camera-dictionary 的使用边界）
- 中英双语按模型分流：SD/MJ/Niji 用英文（CLIP 中文有损耗）；即梦/Seedream 用中文（中文语义第一梯队）；Flux 皆可、涉文化细节用母语。同一资产中英文版语义必须一致

## 二、一致性两层控制（换场景人不变）

**第一层：人物基准（建立身份）**——先用纯白/浅灰背景生成三视图或标准证件照，锁身份：

> 严格基于参考人物（Strictly based on the uploaded character reference）：正面特写 + 45° 侧面 + 背面全身，中性表情，双眼平视，纯浅灰背景，五官、发型、服装高度一致。

**第二层：场景融合（人物进场景）**——把人物放进新场景时锚定人物+统一光线，不是只堆关键词：

> 与参考人物同一人（In the same style as the reference character），〔人物动作〕，置身于〔具体场景描述〕，**人物面部光线必须与环境光一致**，真实阴影投影（the lighting on the character's face must match the ambient light, realistic shadow projection），〔景别〕，〔风格句〕。

两层配合 = 跨镜同人的行业标准做法；单靠关键词堆砌必漂。

三条硬规则（2026-10-27 调研修正）：
- **参考图显式输入位**：只写角色名 ≠ 模型拿到角色图——露脸镜头必须显式携带角色参考图输入位，文本提及不算挂参
- **多参考图写「每图职责」**：多图融合必须逐图写明职责（「图一供人物、图二供场景、图三供服装」），参考关系混乱是多图融合头号翻车点
- **一图一变量**：批量出图一次只变一项（动作/景别/表情/服装/场景），全变必漂；先锚点后扩散

## 三、景别 / 角度控制词（中英对照）

| 中文 | English | 用途 |
|------|---------|------|
| 特写 | Close-up / CU | 面部表情或细节 |
| 中景 | Medium Shot / MS | 腰部以上，对话与半身动作 |
| 全身照 | Full Body Shot | 完整穿搭与站姿 |
| 近景 | Bust shot / Close shot | 胸部以上 |
| 全景 | Wide shot / Long shot | 人小景大，交代空间 |
| 鸟瞰视角 | Bird's-eye view | 俯视，空间气势 |
| 仰视视角 | Low-angle shot | 威压感/气势 |
| 平视视角 | Eye-level angle | 中性叙事 |
| 45 度角 | 45-degree angle | 侧写，立体感 |

## 四、组装五段式（出图指令总装）

```
〔风格段（取自风格 skill）〕+ 〔内容段（七要素的 1–4 项）〕+ 〔光影段（lighting-system 三层）〕+ 〔构图锁〕+ 〔负面段（按 backends 方言）〕
```

- 长度：无字数上限（2026-11-05 用户令废除红线）；每镜 ≥250 字保底写详细。长度上限属后端方言（backends.md），即梦/Seedance 无上限
- **光影段写光影四件套**（光源位置+类型+色温/时段）并逐镜复制——同场景多镜统一最便宜的杠杆
- **负面段按通道分流**（调研实测）：SD/SDXL 真负面框 5–15 精准词；MJ `--no` 仅 3–5 词（「without X」会被反读）；Flux/GPT-Image/Nano Banana/即梦**无负面通道**一律正向改写（「no crowds」→「empty plaza, solitary figure」）
- **风格互斥词按风格分流**：cel 系（style-anime / style-pixar）禁入 85mm/DSLR/photorealistic/skin pores（写实词冲掉动画感）；**style-cg-refined（主风格，半写实精致 CG）反向禁入 cel 词**（平涂/描边/色块），且相机词（IMAX/Panavision/胶片/光圈）是合法武器
- **视频层负面黑名单**（出视频指令的负面段基础词）：五官扭曲、肢体畸形、多余手指、服装错乱、角色变脸、画面闪烁、帧间漂移（视频一致性规则见 `skills/video-producer/references/video-consistency.md`）
- 构图锁：防翻车排版禁令（禁背景混入/禁多格/禁文字气泡等，各资产模板自带）
- t2i / i2i 选择表：

| 资产 | 方式 | 挂参 | 原因 |
|------|------|------|------|
| 主体三视图 | t2i | 无 | 文字控构图；i2i 锚死视角景别 |
| 服装三视图 | i2i | 主体三视图 | 同人同机位只换装 |
| 表情表 | i2i | 主体三视图 | 同脸锁五官 |
| 场景主图 | t2i | 无 | 全新空间 |
| 场景变体 | i2i | 场景主图 | 同空间改道具 |
| Q 版 | i2i | 主体三视图 | 显式禁多视图排版 |
| 人物×场景融合图 | i2i | 人物基准图 | 用 §二 第二层模板 |
