# 剧本内核参考（script-core · 参照非模板）

> 2026-10-27 用户立标：《丧尸清道夫》故事脚本（全文见试产项目 `analysis/标准范本_丧尸清道夫.md`）是**内核参考**——不是照抄的格式标准，是故事灵魂与叙事质感的参照系。**吸收它的 DNA，不是填它的模板。** 与 `script-craft.md`（文笔技法）配套：craft 管「怎么写得好」，本文件管「故事的魂长什么样」。

## 〇、内核参照（从范本里要吸走的东西，比格式重要）

1. **每个故事要有内核**：先想清楚「这故事真正讲什么」（孤独的灵魂渴望陪伴、冰冷机械比人更懂爱）——内核是故事的魂，情节是为它服务的外壳；写之前答得出「内核一句话」才动笔
2. **反差是骨相**：荒芜末世 × 极致温柔、残酷杀戮 × 黑色幽默——题材对撞产生荒诞张力，每个场景都在经营反差
3. **幽默与温情是血肉**：与尸体共舞、头颅当足球、骚包示好——笑点具体到动作；温情笨拙又虔诚（「把末世仅存的所有温柔赠予一具无声的假人」）——吓完就笑、笑完扎心
4. **叙事是流畅的电影语言**：动作链推进、镜头语言入文（画面一转/蒙太奇）、情绪有曲线、结尾有仪式感——读一遍脑里在放电影
5. **设定为叙事服务**：人物/场景/道具写到「能出图」的细度（材质/光线/结构），但从故事里长出来，不是先堆设定再填空

**判定法始终一条：读一遍——脑子里能不能放出电影？放不出 = 打回。**

## 〇之二、载体建议（七段式——怎么装这些内核，可裁剪）

> 下面的结构是范本的载体形态，供采用与裁剪；**内核（上节五条）才是硬要求**。

## 一、七段式载体（每集一份，段序可裁剪，内核不可裁）

| 段 | 内容 | 写法要点 |
|----|------|---------|
| **1 故事背景** | 时代/事件/现状/任务逻辑 | 一段流畅叙话说清「故事发生在哪、为什么会这样、主角在干嘛」——不是设定罗列，是电影开场白 |
| **2 风格核心** | 风格词 + 反差原则 | 一句话定 3–4 个风格词（如「原子朋克、丧尸危机、末日爱情、黑色幽默」）+ **一句反差原则**（如「唯美浪漫的氛围与末日丧尸形成强烈的荒诞反差」）——反差是这类剧的灵魂，必须点명 |
| **3 故事内核** | 这故事真正讲什么 | 主题升华两段式：①内核一句话（「冰冷机械的极致孤独，一场无人知晓、极致纯粹的浪漫」）②外壳/内核对照（「以…为外壳，内核却是…」）——给故事装灵魂，观众记的是内核 |
| **4 人物设定** | 每人一段 | 公式：**形态/身份 + 设计风格 + 标志性机制 + 服装逐件 + 气质词**。写「看得见摸得着」的：材质（哑光皮衣）、结构（关节拼接）、机制（LED 屏幕静帧表情+切换音效） |
| **5 场景设定** | 每景一段 | 公式：**时代风格锚 + 氛围状态（大战过后/死寂）+ 光线（时段+质感：正午刺眼阳光漫射/丁达尔光效/蓝调时刻）+ 环境细节（建筑/道具/痕迹）+ 氛围词（奢华松弛/慵懒）+ 反差句收尾**（「休闲惬意的环境与丧尸的尸体形成极大的反差对比」——反差句每景都写，它就是风格） |
| **6 道具设定** | 关键道具 | 形态/尺寸/结构细节/功能（「圆柱体雷管炸弹，长15cm，直径5cm，顶部有按钮开关……充能到达峰值后爆炸」）——道具是剧情机关，要写到能出图 |
| **7 故事内容** | **完整叙事文本** | 本体！写法见 §二 |

## 二、故事内容的叙事语法（核心技法，逐条抄进写作）

1. **叙事散文体，不是节拍表**：段落=场，一气呵成地「讲」故事——有人物、有动作、有情绪、有画面，读起来像导演口述的电影
2. **转场词就是镜头语言**：「画面一转」「镜头一转」「画风一转」「（蒙太奇手法）」「（利用跳切手法衔接每一个场景）」——转场方式直接写进叙事，分镜师照抄
3. **动作链驱动**：每段一串连贯动作（游荡→爆头→收枪→跳舞→惊扰→破窗→狂飙→抛雷→震飞→翻滚→起身→击杀→造型收尾）——剧情靠动作推进，不靠解说
4. **情绪线明暗交织**：麻木→孤独→惊喜→狂欢→心动→温柔→不舍→圆满——情绪有曲线，段段都在推进
5. **黑色幽默落点**：与尸体共舞、头颅当足球踢、骚包且油腻、骂骂咧咧——荒诞反差的笑点要具体到动作
6. **状态词点睛**：四字/短语状态词钉人物状态（身手利落、杀伐果断、笨拙又虔诚、气急败坏、恋恋不舍）——一句顶一段描写
7. **反差写明**：关键处把反差点破（「残酷末世与极致温柔的反差，形成独特的黑色幽默质感」）
8. **伏笔与蒙太奇反转**：拍立得纪念品→结尾「镜头一转，假人模特出现在画面里」——结尾的反转钩子靠前面埋的道具
9. **收尾句式**：「……画上圆满句号。至此，影片结束。」——每集（或全片）有仪式感的收束

## 三、百集漫剧的落地用法

- **每集一份七段式**：故事背景=本集在全剧中的位置（1–2 句即可）；风格核心=全剧常量复用；故事内核=本集情绪/主题落点；人物设定=**本场出场人**（详写新出场，老角色可简写+锚点引用）；场景设定=本集场景（按 §一公式）；道具=本集关键道具；故事内容=本集完整叙事
- **头部元数据行保留**（下游机器读取）：`集数 / 时长秒（正片 60–120 自动；30–60 秒仅引流切片——2026-10-31 校准：原 30–120，30 秒档低于主流正片口径【社区共识·DramaSo/数艺社】）/ 人物[] / 本集看点 / 结尾钩子`——「句号收尾」=**单句号**，禁「。。」重复标点（2026-10-28 剧本审查实锤：十集 18 处双句号，验收细则缺位所致）
- **集与集承接**：本集故事内容的收束句 = 下集故事背景的引子；结尾钩子=最后的画面反转或悬念
- **写作顺序**：先写故事内容（把戏讲好）→ 再倒填人物/场景/道具设定（从叙事里提取）→ 最后磨背景/内核——设定为叙事服务，不是先堆设定再填空

## 四、验收（三稿制过完后，逐集人读——内核五问）

1. 内核在场：「这集真正讲什么」一句话答得出，情节都在为它服务
2. 故事内容能「放电影」：每段有画面、动作连贯、转场有词
3. 情绪曲线在：至少一处紧张/一处笑点/一处情绪落点
4. 反差成立：题材对撞的张力在故事内容里能读到
5. 幽默温情在：笑点具体到动作，温情笨拙可感
6. 设定够用：人物/场景/道具细到能直接出图（材质/光线/结构齐）
7. 结尾仪式感：收束句在场；钩子能勾住下一集

任何一问不过 → 回精修；两问不过 → 重写该集。
