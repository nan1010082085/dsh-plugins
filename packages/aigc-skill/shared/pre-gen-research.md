# 出图前置调研工序（research-before-gen）

> 用户 2026-10-27 强调的固定工序：**每次出图前**先检索资料——这种风格该怎么出图、提示词怎么写才精准、别人的翻车点——对齐核心要素再出指令，结论沉淀回风格库。
> 这是留存主轴「人物建模质量」的三件套之一（三视图锚点制 + 出图前置调研 + 风格库，`shared/hard-gates.md` 第 9 节）。
> **流程口诀：检索 → 对齐 → 出指令 → 沉淀。** 四步缺一 = 工序未走完，禁止出图。

## 一、什么时候做

- **每次出图批次前必做一次**（同一风格、同一部剧的连续批次可复用上一轮结论，但要在沉淀区确认无新增翻车）。
- 换风格、换模型/工具、换资产类型（如首次做表情表/Q 版/场景空镜）时**重新调研**。
- 重制老翻车资产前，先查翻车点对策再改指令。

## 二、检索关键词策略

按「风格 × 资产类型 × 问题域」三轴组词，中英双语各搜一轮：

| 轴 | 关键词模板（示例） |
|----|------------------|
| 风格 | `cel-shading character prompt` / `3D 卡通渲染 出图 提示词` / `日漫 二次元 角色设定 提示词` / `Pixar style prompt consistent` |
| 资产类型 | `character turnaround three-view prompt` / `AI 角色三视图 提示词` / `expression sheet prompt` / `角色一致性 参考图` |
| 问题域 | `一致性 翻车 对策` / `consistency tips image gen` / `negative prompt anime` / `i2i 参考图 锚构图` |

- 每轮至少覆盖：**出图要点**（这种风格怎么出）、**提示词写法**（什么词有效）、**翻车点**（别人踩什么坑）三类内容。
- 找不到对口资料时放宽到通用角色一致性/三视图资料；仍没有 = 该条结论标注「推测」。

## 三、结论对齐核心要素清单

调研结论必须逐项对齐**六个核心要素**，缺哪项补哪项，再出指令：

1. **主体**——外貌锚点怎么写才锁得住（脸型/发型/瞳色/国籍/辨识配饰；特征具体化）；
2. **三视图**——排版与同条件锁（三张并排/同站姿/同机位/脚底同基线/背景纯色）；
3. **表情**——表情解剖写法（每格写满写差异，外貌只在布局头写一次）；
4. **多套服装**——逐件写死+配饰拆解+i2i 挂主体同光影/站姿/机位；
5. **风格质感**——该风格的质感词与负面词（平涂/线稿/光泽渲染等，取自对应**风格 skill** 的 style-profile.md）；
6. **跨镜一致性**——特征短语复述、参考图用法（引用主体/i2i 构图硬锁）、命名与版本纪律。

同时核对硬闸不被调研来的写法带偏：禁废话词、广告闸（素色无品牌+禁包装特写）、情绪可视化（`shared/hard-gates.md`）。

## 四、出指令

- 用对应**风格 skill** 的 style-profile.md **风格锁模板**起稿（风格选择见 `shared/style-library.md` 索引），按核心要素清单逐项填入剧本设定。
- 负面词按风格负面表 + 通用基础表组装（10 个针对性词 > 50 词堆砌；无负面通道改正向描述）。
- 出图后按 `skills/character-studio/references/character-asset-system.md` 与 `skills/scene-studio/references/scene-asset-system.md` 的一致性硬规则与验收清单逐张核对；翻车按「停 → 定位正向缺还是负面缺 → 最小修改原指令重跑」处理。

## 五、沉淀回风格库（引用不复述）

- 新结论**追加**到对应**风格 skill** 的 `style-profile.md`「翻车点与对策」一节，标注日期与来源（沉淀路由见 `shared/style-library.md` §三）；库已有的条目**引用即可，不复述全文**。
- 沉淀三类内容：新发现的出图要点、验证有效的提示词句、新翻车点与解法；标注「推测」的条目经实测验证后去掉标注。
- 与库内条目冲突时：新实测 > 旧结论，改库并注明修订日期；与硬闸冲突时以硬闸为准并改库。
- **未沉淀 = 工序未完成**（与 ima-upload 同为完成条件）：会话里修好的提示词不落库，下个会话照旧翻车。
