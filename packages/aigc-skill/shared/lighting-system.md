# 三层光影体系（Lighting System）

> 供 storyboard-director / character-studio / scene-studio 在提示词中写光影的统一语法。每镜的光影描写按**环境层→主光层→情绪层**三层拼装，缺层=光影失控（忽明忽暗、同场不同光）。
> **使用规则**：
> 1. 同一场戏的**环境层+主光层必须全镜一致**（同场同光是接戏底线），只有情绪层可随剧情微调；
> 2. 提示词中光影段写法：`环境层一句 + 主光层一句 + 情绪层一句`，共 2–3 句，不写超过 3 句（写多必糊）；
> 3. 光影配方表是**起点不是枷锁**——按剧情微调方向/色温，但不要整层推翻；
> 4. 与 `shared/director-styles.md` 冲突时，风格库的光影偏好优先（风格是全剧基调）。

---

## 一、环境层（Ambient Layer）——"这地方的光是什么样"

**职责**：定义场景的基础照度与底色，回答"环境光从哪来、有多亮、什么底色"。包括天光、环境反射光、整体雾气/空气感。环境层决定画面的**黑位**（暗部是否死黑）与**整体色偏**。

**写什么**：
- 时间与天气带来的基础光（正午阳光、阴天漫射、夜色、室内灯光环境）
- 空气介质（雾、尘、雨、烟）造成的通透度
- 暗部基调（暗部保留细节 or 深黑剪影）

**示例**：
- 日戏室外：`阴天柔和漫射天光，整体照度均匀，暗部保留细节`
- 夜戏街道：`夜色为深蓝底调，环境光来自街灯与招牌溢光，暗部深黑但保留轮廓`

## 二、主光层（Key Layer）——"主光从哪打、什么质感"

**职责**：定义画面的**主光源**（方向、色温、软硬），塑造主体体积与立体感。主光层是画面的"骨架"，决定脸好不好看、形体是否立得住。一镜只允许 **1 个主光**（多主光=光影混乱）。

**写什么**：
- 光源方向（顺光/侧光/逆光/顶光/底光）与光源实体（窗户、台灯、月亮、火光）
- 软硬（柔光/硬光）与色温（暖/中性/冷）
- 与环境层的关系（主光压过环境光 or 融入环境光）

**示例**：
- 窗边对话：`主光为左侧窗户射入的柔和日光，色温中性偏暖，主光略强于环境光`
- 月下对决：`主光为右上方冷白月光硬光，雕刻面部轮廓，主光明显压过环境光`

## 三、情绪层（Mood Layer）——"这场戏要什么情绪"

**职责**：在环境层+主光层之上做**情绪修饰**，包括对比度、轮廓光/边缘光、色光点缀、阴影质感、光效（光斑、丁达尔、镜头光晕）。情绪层按剧情点起伏，是三张牌里唯一允许逐镜变化的。

**写什么**：
- 对比度与影调（高调明亮/低调压抑/中间调）
- 轮廓光、眼神光、剪影等塑形修饰
- 色光点缀（霓虹映色、火光跳动、蓝调阴影）与情绪光效（光晕、光柱、闪烁）

**示例**：
- 告白：`低对比柔和影调，发丝轮廓光，轻微暖色光晕，阴影过渡绵软`
- 悬疑：`高对比低调影调，半脸藏于阴影，阴影边缘锐利，仅留眼神光`

## 四、情绪光影配方表

> 每种情绪一行配方：**光源方向 / 色温 / 对比度 / 阴影质感** + 可直接复制的提示词句。色温以开尔文（K）表述：数值越低越暖、越高越冷。
>
> **色温物理锚（2026-10-31 入库）**【行业：StudioBinder 色温定义；影视灯具行业规格】：烛光 ~1500K、**日出/日落 3200K**（=钨丝灯规格）、自然日光 5500K（灯具行业通称 5600K）、蓝天 12000K；K 值越高越冷（蓝）、越低越暖（黄）；白平衡设定值以上偏冷、以下偏暖。暖调=温暖感、冷调=疏冷/紧张感的情绪关联=**行业惯例（color theory psychology），非标准**。
> **配方数值档位（2026-10-31 批4 核验·被校正条目留注记）**：下表各档色温区间与「暗部占比 <15% / 60% 以上暗部」等百分比**全部=【经验·内部】风格配方值，可调，无行业标准**；色温的物理锚（上行）有据，但各档区间数值是内部调配、**情绪用途属行业惯例非标准**，禁止对外标成行业依据。配方表是起点不是枷锁（使用规则 3）。

### 喜（Joy / 高兴）

| 项 | 配方 |
|----|------|
| 光源方向 | 顺光或 3/4 侧前光，正面照亮面部，阴影不遮表情 |
| 色温 | 阳光暖 4500–5200K，比温馨档稍冷的奶油阳光调【经验·内部】 |
| 对比度 | 低对比高调（明亮通透，暗部占比 <15%）【经验·内部】 |
| 阴影质感 | 极柔的边缘过渡，几乎无硬阴影 |

**提示词句**：
> 明亮暖调的顺光，奶油色暖光正面照亮面部，低对比高调影调通透明亮，阴影柔和近乎无痕，整体欢快开朗。

### 怒（Anger / 愤怒）

| 项 | 配方 |
|----|------|
| 光源方向 | 顶光或低位硬侧光（下方偏侧，压迫式塑形） |
| 色温 | 偏暖燥 3800–4500K 或火光橙红【经验·内部】 |
| 对比度 | 高对比，明暗反差强烈 |
| 阴影质感 | 硬边阴影，阴影浓重盖住部分面部（眉骨、眼窝深影） |

**提示词句**：
> 硬质顶侧光雕刻面部棱角，燥暖橙红光调，高对比强反差，硬边浓重阴影压住眼窝，剑拔弩张的怒意。

### 惊（Shock / 震惊）

| 项 | 配方 |
|----|------|
| 光源方向 | 顶光或正面直打（审讯灯式），瞬间提亮 |
| 色温 | 中性偏冷 5600–6500K，苍白感【经验·内部】 |
| 对比度 | 高对比高调（亮部过曝边缘+深黑暗部并存） |
| 阴影质感 | 短促硬阴影，眼窝鼻下生硬投影，瞳孔收缩感 |

**提示词句**：
> 苍白冷光正面直打如审讯灯，高对比的亮部刺眼与深黑暗部并存，短促硬阴影投在眼下，瞬间凝固的惊骇感。

### 悲（Sadness / 悲伤）

| 项 | 配方 |
|----|------|
| 光源方向 | 逆光或单一侧光，面部大面积欠曝 |
| 色温 | 冷 6500–8000K，蓝调阴影【经验·内部】 |
| 对比度 | 中低对比的低调（整体偏暗，主体在半影中） |
| 阴影质感 | 柔边但大面积的阴影，面部半明半暗，泪光处留一点高光 |

**提示词句**：
> 冷蓝逆光勾勒孤单轮廓，面部大面积隐入柔和阴影，低调整体偏暗，泪光处一点微弱高光，压抑低落的悲伤氛围。

### 悬疑（Suspense / 悬疑）

| 项 | 配方 |
|----|------|
| 光源方向 | 单侧窄光（百叶窗光/门缝光），只照亮局部 |
| 色温 | 冷中性 6000–7000K，可加微量青绿【经验·内部】 |
| 对比度 | 高对比低调（画面 60% 以上为暗部）【经验·内部】 |
| 阴影质感 | 锐利硬边阴影条纹，阴影中藏信息（看不清的角落） |

**提示词句**：
> 门缝窄光斜切画面只照亮半脸，冷中性光调微泛青绿，高对比低调大面积暗部，锐利的条纹硬阴影，未知感拉满的悬疑氛围。

### 温馨（Warmth / 温馨）

| 项 | 配方 |
|----|------|
| 光源方向 | 3/4 侧暖光或环境光包裹（台灯、壁炉、夕阳窗光） |
| 色温 | 暖 3200–4200K，琥珀/蜜糖色【经验·内部】 |
| 对比度 | 低对比中间调，暗部暖而不黑 |
| 阴影质感 | 柔边暖阴影，阴影里也有色彩（不发灰发脏） |

**提示词句**：
> 琥珀色暖光从侧面包裹人物，蜜糖色暖调低对比中间调，柔边暖阴影保留色彩，壁炉光微微跳动，安宁治愈的温馨氛围。

## 五、拼装示例（环境层 + 主光层 + 情绪层）

**日戏·温馨对话镜**：
> 阴天柔和漫射天光，整体照度均匀；主光为左侧窗户日光 3/4 侧前打亮双人面部，色温中性偏暖；低对比中间调柔边阴影，发丝微轮廓光，安宁温馨。

**夜戏·悬疑窥视镜**：
> 夜色深蓝底调，暗部深黑保留轮廓；主光为右上方冷白月光侧光；门缝窄光条纹斜切，高对比低调，锐利硬阴影，未知感拉满。

**打戏·愤怒爆发镜**：
> 火光橙红映照的夜间环境，烟尘弥漫；主光为低位火光硬光从左下打亮面部；高对比强反差，硬边浓重阴影压住眼窝，燥热愤怒。
