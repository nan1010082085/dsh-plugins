# 跨 Skill 数据契约（output-formats）

> **LOCKED —— 本文件的字段名是锁定契约，后续任务（分镜/素材/检查）一律引用原名，禁止改名、别名、增删字段。**
> 五个 skill 之间只通过本文件的字段契约耦合：`novel-to-drama` / `idea-to-drama` 产剧本条目 → `character-studio` / `scene-studio` / `prop-studio` 产 assets.json＋视觉元数据（lora_registry，**先建资产后写分镜**，@引用全指向已建成素材）→ `storyboard-director` 引用资产产分镜块（提示词由 prompt_compiler 按后端编译）→ `shot-qa` 产检查报告。出片后 `clip-review` 五项核验+缺陷归因+回流（核验报告为交付件）。【执行顺序 2026-10-30 用户重排：剧本 → 素材 → 分镜】
> 字段名以本文件为唯一真相源；与任何 skill 文案冲突时，改 skill 文案，不改本契约。

## 1. 剧本条目（skill：novel-to-drama / idea-to-drama）

```
{
  集数,            // 第几集（整数，全局连续）
  时长秒,          // 60–120 正片（30–60 仅引流切片），自动——由节拍与分镜自然成型，不硬凑（2026-10-31 校准：原 30–120，只改注释文案，字段契约本体不变）
  场景节拍[],      // 节拍数组，见下
  人物[],          // 本集出场人物名，与 assets.json 的 characters.name 对齐
  本集看点,        // 一句话，句号收尾
  结尾钩子         // Cliffhanger 一句话，句号收尾
}
```

**节拍**（`场景节拍[]` 的元素）：

```
{
  目标/冲突,       // 本节拍的目标或冲突（字段名含斜杠，照写）
  起承转合,        // 哪怕很短也要齐
  钩子            // 节拍尾钩（可与本集结尾钩子同源）
}
```

约束：单集 1–3 个场景；一集一个微事件；`人物[]` 逐人可挂资产（露脸角色全挂）。

## 2. 分镜块（skill：storyboard-director）

```
{
  镜号,            // 全集连续编号
  时间片[],        // 格式「\d+[–-]\d+ 秒」；每时间片一个动作、一个运镜；单镜 >15s 自动分段
  六要素{
    主体外貌,      // 固定长相锚点，逐人写全（多人镜逐人格位/外貌/动作/台词）
    动作,
    场景,
    光影,
    焦段运镜,      // 用 shared/camera-dictionary.md 的安全运镜词（中文，禁裸英文）
    音效
  },
  转场交代?,       // 可选字段名固定为「转场交代」；场景/时间变化的进场镜必填：时间+地点+转场过渡句（明写不硬切）
  素材映射[],      // 本镜挂的人物/场景资产（对齐 assets.json）；露脸角色全挂、场景必挂
  提示词           // 交付物 = 代码块完整提示词，可直接复制即梦出片；中文 ≤500 字
}
```

约束：每镜细节下限 250 字保底、不限字数上限但必须详细描写；`提示词` 必须以代码块交付。

**剧本深度标准（2026-10-27 用户令，最高优先级——「几行节拍不算剧本」）**：剧本条目必须含**分场叙事**节——逐场戏具体叙事，每场 **300–500 字画面叙事**（环境/动作/表情/光影/道具/声音写满，能直接喂分镜、能读出故事），台词带语气标注，音效/环境声逐场标注，末尾带转场备注。只有节拍+台词占位 = 提纲，打回重写。

## 3. 素材注册表 assets.json（skill：character-studio + scene-studio + prop-studio）

```
{
  "characters": [
    {
      "name",
      "visual_id",     // 身份锚 ref，格式 node_+10 位小写字母数字
      "three_view",    // 主体三视图（身份锚，永久）
      "face_card",     // 面部身份卡/色卡
      expressions[],   // 表情表数组
      "outfits": [
        {
          "名",        // 服装套名（字段名就是「名」）
          "three_view", // 该套服装三视图
          "配饰"       // 逐件配饰拆解（字段名就是「配饰」）
        }
      ]
    }
  ],
  "scenes": [
    {
      "名",            // 场景名（字段名就是「名」）
      "image",         // 纯空镜场景图（无人）
      "光影锁定"       // 该场景的光影锁定值，同场景多镜共用（字段名就是「光影锁定」）
    }
  ],
  "props": [
    {
      "名",            // 道具名-状态（状态为常态时省略，如「白瓷茶壶」「笔记本-翻开第3页」）
      "类别",          // '通用' | '角色专属'
      "所属角色",      // 角色名或 '通用'
      "造型锚点",      // 形状/花纹/材质/颜色/尺寸写死，跨状态跨镜复述一字不差
      "状态": [],      // 该道具的状态清单（每状态一张图、独立素材）
      "image",         // 白底/透明底 PNG（复杂道具三视图/简单道具主视图）
      "比例参考",      // 大小比例参考（如「与成年男性手掌对比」）
      "备注"
    }
  ]
}
```

约束：场景图必须纯空镜（有人场景不能用于出视频）；同场景多镜共用同一套场景资产；道具状态=独立素材（各状态分开存图命名），状态变体只准 i2i 挂主图（禁重新 t2i）；每镜按分镜块的 `素材映射[]` 挂参。

## 4. 检查报告（skill：shot-qa）

```
{
  价格闸{
    报价,          // 逐镜报价（单价×数量）+ 账单上限
    批准           // 用户批准记录（批准人+上限）；未批准不得出片
  },
  剧情校验{
    逐字,          // 分镜↔剧本逐字一致（SHA-256 级，零压缩搬运）
    转场,          // 转场交代齐（时间+地点+过渡句）
    品牌,          // 广告植入扫描（品牌词表+包装词，三层：画面/语音/字幕）
    违禁           // 违禁词/废话词/每镜≥250 字/看点钩子句号收尾
  },
  素材校验{
    挂载,          // 每镜该挂的人物/场景资产挂齐（露脸角色全挂、场景必挂）
    格式,          // ref ID 格式 node_[a-z0-9]{10}，节点存在且 success
    验真           // 生成后只认提交后新 resource（submission.resources，createdAt 晚于提交）
  }
}
```

约束：三闸全过才准出片；任一项 FAIL 打回对应环节重做，禁止带病出片。

## 5. 交付链路一览

```
剧本条目{集数, 时长秒, 场景节拍[], 人物[], 本集看点, 结尾钩子}
  → 分镜块{镜号, 时间片[], 六要素{主体外貌,动作,场景,光影,焦段运镜,音效}, 转场交代?, 素材映射[], 提示词}
  → assets.json{characters:[{name, visual_id, three_view, face_card, expressions[], outfits:[{名, three_view, 配饰}]}], scenes:[{名, image, 光影锁定}]}
  → 检查报告{价格闸{报价, 批准}, 剧情校验{逐字, 转场, 品牌, 违禁}, 素材校验{挂载, 格式, 验真}}
```
